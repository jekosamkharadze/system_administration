DNS(Domain Name System) არის სისტემა, რომელიც დომენის სახელს შესაბამის IP მისამართს უკავშირებს.

ჩვენთვის  მარტივია დავიმახსოვროთ:

google.com

მაგრამ კომპიუტერს სერვერთან დასაკავშირებლად IP მისამართი სჭირდება. DNS პოულობს ამ IP-ს.

მაგალითად:

google.com → 142.250.x.x

როგორ მუშაობს?

როდესაც ბრაუზერში წერ google.com:

კომპიუტერი → DNS Server → IP Address → სერვერი

DNS-ის გარეშე დომენების ნაცვლად IP მისამართების დამახსოვრება მოგვიწევდა.

DNS და Gateway-ის განსხვავება
DNS — პოულობს დომენის შესაბამის IP მისამართს.
Gateway — უზრუნველყოფს სხვა ქსელებში, მათ შორის ინტერნეტში, გასვლას.

მოკლედ:
DNS = სახელი → IP
Gateway = ჩემი ქსელიდან სხვა ქსელში გასასვლელი.
