MAC Address (Media Access Control Address) არის უნიკალური იდენტიფიკატორი, რომელიც დაკავშირებულია ქსელურ ინტერფეისთან (NIC) და გამოიყენება ლოკალურ ქსელში მოწყობილობის იდენტიფიცირებისთვის.

MAC Address მუშაობს ძირითადად OSI Model-ის Data Link Layer-ზე (Layer 2) და განსაკუთრებით მნიშვნელოვანია Ethernet და Wi-Fi ქსელებში.

MAC Address ჩვეულებრივ წარმოდგენილია 48-ბიტიანი (6-ბაიტიანი) მნიშვნელობის სახით. მაგალითად:

00:1A:2B:3C:4D:5E

აქ თითოეული ორი სიმბოლო წარმოადგენს ერთ ბაიტს და მთლიანობაში გვაქვს 6 ბაიტი.

MAC Address-ის პირველი ნაწილი დაკავშირებულია მწარმოებელთან და მას OUI (Organizationally Unique Identifier) ეწოდება, ხოლო დარჩენილი ნაწილი კონკრეტული ქსელური ინტერფეისის იდენტიფიცირებისთვის გამოიყენება.

მაგალითად, როდესაც ერთი კომპიუტერი მეორეს უგზავნის მონაცემს ერთ LAN-ში, Ethernet Frame-ში მითითებულია Source MAC Address და Destination MAC Address. Switch ამ ინფორმაციას იყენებს იმისთვის, რომ განსაზღვროს, რომელ პორტზე უნდა გადააგზავნოს Frame.

მაგალითად:

PC1 → Switch → PC2

PC1-ის NIC-ს აქვს ერთი MAC Address, PC2-ის NIC-ს — მეორე. Switch სწავლობს ამ მისამართებს და ქმნის MAC Address Table-ს, მაგალითად:

00:11:22:33:44:55 → Port 1

AA:BB:CC:DD:EE:FF → Port 4

თუ Switch-მა იცის, რომ დანიშნულების MAC Address Port 4-ზეა, Frame-ს შესაბამის პორტზე აგზავნის.

MAC Address და IP Address ერთმანეთისგან განსხვავდება. MAC Address ძირითადად გამოიყენება ლოკალურ ქსელში Data Link Layer-ზე, ხოლო IP Address გამოიყენება ქსელებს შორის კომუნიკაციისა და Routing-ისთვის.

მაგალითად:

MAC Address → „რომელი Network Interface არის?“

IP Address → „რომელ ქსელში/მისამართზე უნდა წავიდეს მონაცემი?“

MAC Address ჩვეულებრივ ქსელურ ინტერფეისთან არის დაკავშირებული, თუმცა ზოგიერთ სისტემაში შესაძლებელია მისი დროებით შეცვლა ან spoofing პროგრამული საშუალებით. ამიტომ MAC Address არ უნდა აღვიქვათ როგორც მოწყობილობის აბსოლუტურად უცვლელი ან უსაფრთხო იდენტიფიკატორი.

დასკვნა: MAC Address არის Network Interface-ის Layer 2 იდენტიფიკატორი, რომელსაც LAN-ში მოწყობილობების ერთმანეთისგან გასარჩევად და Ethernet/Wi-Fi Frame-ების გადასაცემად იყენებენ. Switch სწორედ MAC Address-ების საფუძველზე განსაზღვრავს, რომელ პორტზე უნდა გადააგზავნოს მონაცემი.
