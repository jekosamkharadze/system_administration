
Routing (მარშრუტიზაცია) არის პროცესი, რომლის დროსაც Router განსაზღვრავს, რომელი გზით უნდა გაიგზავნოს IP პაკეტი დანიშნულების ქსელამდე.


Router აკავშირებს სხვადასხვა IP ქსელებს ერთმანეთთან და პაკეტებს შესაბამისი მიმართულებით აგზავნის.

მაგალითად:
PC → Router → Internet → Server

თუ კომპიუტერისა და სერვერის IP მისამართები სხვადასხვა ქსელშია, მათ შორის კომუნიკაციისთვის საჭიროა Router.


Routing Table არის ცხრილი, რომელსაც Router იყენებს იმის დასადგენად, სად და რა მიმართულებით უნდა გაგზავნოს პაკეტი.

მაგალითად:
Destination       Next Hop
192.168.1.0/24    Direct
192.168.2.0/24    192.168.1.2
0.0.0.0/0         192.168.1.1

ძირითადი ელემენტები:

Destination — დანიშნულების ქსელი, სადაც პაკეტი უნდა მივიდეს.

Next Hop — შემდეგი Router ან მოწყობილობა, რომელსაც პაკეტი უნდა გადაეცეს.

Interface — Router-ის ინტერფეისი, საიდანაც პაკეტი უნდა გავიდეს.



Default Gateway — მოწყობილობისთვის სხვა ქსელებში გასასვლელი მისამართია.

Routing — პაკეტის დანიშნულების ქსელამდე მისასვლელი გზის არჩევისა და გადაგზავნის პროცესია.


Routing-ის მაგალითი:
PC:     192.168.1.10
Gateway: 192.168.1.1
Server:  8.8.8.8

მაშინ:

1. PC ამოწმებს დანიშნულების IP-ს.
2. ხედავს, რომ 8.8.8.8 მის ლოკალურ ქსელში არ არის.
3. პაკეტს უგზავნის Default Gateway-ს.
4. Router ამოწმებს Routing Table-ს.
5. Router არჩევს შესაბამის მარშრუტს.
6. პაკეტი გადადის შემდეგ Router-ზე.
7. პროცესი მეორდება, სანამ პაკეტი დანიშნულებამდე მივა.


## Static Routing

Static Routing არის მარშრუტი, რომელიც ადმინისტრატორმა ხელით დააკონფიგურირა.

მაგალითად:
10.0.0.0/24 → 192.168.1.2

ანუ 10.0.0.0/24 ქსელამდე მისასვლელად პაკეტი უნდა გაიგზავნოს 192.168.1.2-ის გავლით.

## Dynamic Routing

Dynamic Routing-ის დროს Router-ები სპეციალური Routing Protocol-ების საშუალებით ერთმანეთს ქსელების შესახებ ინფორმაციას უზიარებენ და მარშრუტებს ავტომატურად სწავლობენ.

მაგალითად:

* OSPF
* BGP
* RIP
* EIGRP

მთავარი დასამახსოვრებელი:

**IP Address** → მოწყობილობის/ინტერფეისის მისამართი.

**Subnet Mask / Prefix** → განსაზღვრავს ქსელის საზღვრებს.

**Default Gateway** → ადგილობრივი ქსელიდან სხვა ქსელებისკენ გასასვლელი.

**Routing** → პაკეტის გზის არჩევისა და გადაგზავნის პროცესი.

**Routing Table** → ინფორმაცია, რომლის მიხედვითაც Router მარშრუტს ირჩევს.

**Router** → მოწყობილობა, რომელიც სხვადასხვა ქსელებს აკავშირებს და პაკეტებს შესაბამისი მიმართულებით აგზავნის.
