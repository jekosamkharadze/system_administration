Firewall არის ქსელის უსაფრთხოების მექანიზმი, რომელიც აკონტროლებს შემომავალ და გამავალ ქსელურ ტრაფიკს წინასწარ განსაზღვრული წესების მიხედვით. მისი მთავარი მიზანია გადაწყვიტოს, რომელი კავშირი დაიშვას (Allow) და რომელი დაიბლოკოს (Block/Deny).

Firewall-ს შეუძლია შეამოწმოს რამდენიმე მნიშვნელოვანი პარამეტრი: წყაროს IP მისამართი, დანიშნულების IP მისამართი, პროტოკოლი და პორტი. მაგალითად, თუ კომპიუტერზე შემოდის TCP კავშირი 22-ე პორტზე, Firewall-ის წესმა შეიძლება დაუშვას ან დაბლოკოს ეს კავშირი.

Inbound ნიშნავს შემომავალ ტრაფიკს — სხვა მოწყობილობიდან ჩვენს კომპიუტერში ან სერვერზე. Outbound ნიშნავს გამავალ ტრაფიკს — ჩვენი კომპიუტერიდან სხვა მოწყობილობისკენ.

მაგალითად, თუ სერვერზე მუშაობს SSH და მისი პორტია TCP 22, Firewall-ში შეიძლება არსებობდეს წესი, რომელიც უშვებს მხოლოდ კონკრეტული ადმინისტრატორის IP-დან 22-ე პორტზე შემომავალ კავშირს. სხვა IP მისამართებიდან იგივე პორტზე მოთხოვნა დაიბლოკება. ასევე შესაძლებელია კონკრეტული პორტის მთლიანად დაბლოკვა, თუ შესაბამისი სერვისი არ გვჭირდება.

Firewall-ის წესის მარტივი ლოგიკა შეიძლება ასე წარმოვიდგინოთ:

Source IP → Destination IP → Protocol → Port → Action

მაგალითად:

192.168.1.50 → 192.168.1.100 → TCP → 22 → Allow

ეს ნიშნავს, რომ 192.168.1.50-ს შეუძლია 192.168.1.100-ზე TCP 22-ე პორტთან დაკავშირება.

Firewall-ის წესები განსაკუთრებით მნიშვნელოვანია სერვერებზე, რადგან სერვერზე შეიძლება რამდენიმე ქსელური სერვისი მუშაობდეს. მაგალითად, HTTP იყენებს TCP 80-ს, HTTPS — TCP 443-ს, SSH — TCP 22-ს. თუ კონკრეტული სერვისი ინტერნეტიდან არ უნდა იყოს ხელმისაწვდომი, შესაბამისი პორტის შემომავალი წვდომა შეიძლება შეიზღუდოს.

Windows-ში Firewall-ის ფუნქციას ძირითადად Windows Defender Firewall ასრულებს. Linux-ში ხშირად გამოიყენება ისეთი ინსტრუმენტები, როგორიცაა UFW ან firewalld, რომლებიც Firewall-ის წესების მართვას ამარტივებენ.

Firewall არ არის იგივე, რაც NAT. NAT IP მისამართებსა და პორტებს გარდაქმნის, ხოლო Firewall განსაზღვრავს, დაიშვას თუ არა კონკრეტული ქსელური ტრაფიკი. ასევე Firewall არ არის ანტივირუსი: ანტივირუსი ძირითადად ფაილებსა და პროგრამულ მავნე კოდს ამოწმებს, Firewall კი ქსელურ კავშირებს აკონტროლებს.

პრაქტიკაში Firewall-ის მუშაობის ძირითადი პრინციპია: მხოლოდ საჭირო კავშირები უნდა იყოს დაშვებული, ხოლო არასაჭირო წვდომა — შეზღუდული. ამიტომ სერვერზე ან კომპიუტერზე პორტების უბრალოდ გახსნა უსაფრთხოების თვალსაზრისით სასურველი არ არის; თითოეულ გახსნილ პორტს უნდა ჰქონდეს კონკრეტული მიზეზი და დაცული უნდა იყოს შესაბამისი სერვისი.
