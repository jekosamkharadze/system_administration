Default Gateway არის მოწყობილობა, რომლის საშუალებითაც კომპიუტერი თავისი ლოკალური ქსელის გარეთ მდებარე სხვა ქსელებs უკავშირდება. ჩვეულებრივ, სახლში ან ოფისში Default Gateway არის Router-ის ლოკალური IP მისამართი.

მაგალითად, გვაქვს:

PC: 192.168.1.10
Subnet Mask: 255.255.255.0
Default Gateway: 192.168.1.1

აქ 192.168.1.10 არის კომპიუტერის IP, ხოლო 192.168.1.1 არის Router-ის მისამართი ლოკალურ ქსელში.

თუ კომპიუტერს სჭირდება იმავე ქსელში მყოფ მოწყობილობასთან დაკავშირება, მაგალითად:

PC → 192.168.1.20

მონაცემი პირდაპირ ლოკალურ ქსელში იგზავნება და Default Gateway აუცილებელი არ არის.

მაგრამ თუ კომპიუტერს სჭირდება სხვა ქსელში ან Internet-ზე გასვლა:

PC → Default Gateway (Router) → სხვა ქსელი → Internet

კომპიუტერი მონაცემს Router-ს გადასცემს, ხოლო Router შემდეგ გადაწყვეტს, სად უნდა გადააგზავნოს იგი.


ამიტომ Default Gateway შეგვიძლია წარმოვიდგინოთ როგორც „გასასვლელი“ ჩვენი ლოკალური ქსელიდან სხვა ქსელებში.

მნიშვნელოვანია, რომ Default Gateway ჩვეულებრივ უნდა იყოს იმავე Subnet-ში, რომელშიც თავად მოწყობილობაა.

მაგალითად:

PC: 192.168.1.10/24
Gateway: 192.168.1.1 ✅


დასკვნა: Default Gateway არის ქსელის მოწყობილობა, ჩვეულებრივ Router, რომლის საშუალებითაც Host-ს შეუძლია თავისი ლოკალური ქსელიდან სხვა ქსელებში, მათ შორის Internet-ზე, მონაცემების გაგზავნა. ლოკალურ ქსელში კომუნიკაციისას Gateway ყოველთვის არ არის საჭირო, მაგრამ სხვა ქსელთან კომუნიკაციისას ის მნიშვნელოვანი ნაწილია.
