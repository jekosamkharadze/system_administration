TCP და UDP არის სატრანსპორტო პროტოკოლები, რომლებიც განსაზღვრავენ, როგორ გადაიცემა მონაცემები მოწყობილობებს შორის.

TCP (Transmission Control Protocol)

TCP ქმნის სანდო კავშირს და ამოწმებს, რომ მონაცემები სწორად და სრულად მივიდეს.

TCP-ის დროს:

მონაცემების მიღება დასტურდება;
დაკარგული მონაცემი შეიძლება ხელახლა გაიგზავნოს;
მონაცემები სწორ თანმიმდევრობაში ლაგდება;
გადაცემამდე კავშირი მყარდება.

მაგალითად, HTTPS, SSH, FTP ძირითადად TCP-ს იყენებენ.

TCP = საიმედოობა და სისწორე


UDP (User Datagram Protocol)

UDP კავშირის დამყარების გარეშე აგზავნის მონაცემებს. მას ნაკლები კონტროლი აქვს, ამიტომ უფრო სწრაფი და ნაკლები overhead-ის მქონეა, მაგრამ მონაცემის დაკარგვა ან არასწორი თანმიმდევრობით მიღება შესაძლებელია.

მაგალითად, UDP ხშირად გამოიყენება ონლაინ თამაშებში, VoIP-ში, ვიდეო/აუდიო სტრიმინგში და DNS-ში.

UDP = სისწრაფე და ნაკლები overhead

მთავარი განსხვავება
TCP → საიმედო, კონტროლირებადი, კავშირის დამყარებით
UDP → სწრაფი, მსუბუქი, კავშირის დამყარების გარეშე

მნიშვნელოვანი: UDP ყოველთვის „უფრო სწრაფი ინტერნეტი“ არ არის — უბრალოდ პროტოკოლს ნაკლები კონტროლის მექანიზმი აქვს, რაც გარკვეულ აპლიკაციებში დაბალ დაყოვნებასა და ნაკლებ overhead-ს უწყობს ხელს.
