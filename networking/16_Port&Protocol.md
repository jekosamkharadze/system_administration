შემდეგი მნიშვნელოვანი თემაა Network Port — არ უნდა აგვერიოს ფიზიკურ პორტში, მაგალითად RJ-45-ში.

Network Port არის რიცხვითი იდენტიფიკატორი, რომელიც კომპიუტერს ეხმარება განსაზღვროს, რომელ პროგრამას ან ქსელურ სერვისს ეკუთვნის მიღებული მონაცემი.

მაგალითად, ერთ კომპიუტერზე ერთდროულად შეიძლება მუშაობდეს:

ვებ-ბრაუზერი
DNS
SSH
ელფოსტის სერვისი

ყველა მათგანს სხვადასხვა პორტი შეიძლება ჰქონდეს.

მაგალითად როცა ბრაუზერი HTTPS ვებსაიტს უკავშირდება:

IP Address + Port

მაგალითად:

142.250.x.x : 443

აქ:

142.250.x.x → რომელ მოწყობილობასთან/სერვერთან ვუკავშირდებით
443 → რომელ სერვისთან ვუკავშირდებით
ხშირად გამოყენებული პორტები
20/21 → FTP
22 → SSH
25 → SMTP
53 → DNS
80 → HTTP
443 → HTTPS
3389 → RDP

IP და Port ერთად
შეგვიძლია ასე წარმოვიდგინოთ:

IP Address = შენობის მისამართი
Port = კონკრეტული ოთახი ამ შენობაში

მაგალითად:

192.168.1.10:22

ნიშნავს:

მოწყობილობა 192.168.1.10 → SSH სერვისი, პორტი 22.

მოკლედ:
IP განსაზღვრავს მოწყობილობას, Port კი — კონკრეტულ ქსელურ სერვისს/აპლიკაციას ამ მოწყობილობაზე.
