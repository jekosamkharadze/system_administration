Network Security არის ქსელის, მასში არსებული მოწყობილობების, სერვერების, მონაცემებისა და ქსელური კავშირების დაცვა არაავტორიზებული წვდომის, მონაცემების მოპარვის, შეცვლის ან ქსელის მუშაობის შეფერხებისგან. ქსელის უსაფრთხოების მთავარი მიზანია, რომ მხოლოდ უფლებამოსილ მომხმარებლებსა და მოწყობილობებს ჰქონდეთ შესაბამის რესურსებთან წვდომა და ქსელში არსებული სერვისები დაცული იყოს არასასურველი კავშირებისგან.

ქსელის უსაფრთხოების ერთ-ერთი მთავარი კომპონენტია Firewall. Firewall არის უსაფრთხოების მექანიზმი, რომელიც აკონტროლებს ქსელურ ტრაფიკს და წინასწარ განსაზღვრული წესების მიხედვით წყვეტს, რომელი კავშირი უნდა დაიშვას და რომელი უნდა დაიბლოკოს. Firewall შეიძლება იყოს კომპიუტერში არსებული პროგრამული უზრუნველყოფა, Router-ში ჩაშენებული ფუნქცია ან ცალკე ქსელური მოწყობილობა. მაგალითად, თუ სერვერზე HTTPS სერვისი მუშაობს, Firewall შეიძლება უშვებდეს TCP 443 პორტზე შემოსულ კავშირებს, ხოლო სხვა არასაჭირო პორტებს ბლოკავდეს.

ქსელურ უსაფრთხოებაში მნიშვნელოვანია Inbound და Outbound Traffic-ის განსხვავებაც. Inbound Traffic არის ტრაფიკი, რომელიც ქსელის ან მოწყობილობის გარედან შემოდის, მაგალითად Internet-იდან შიდა სერვერისკენ მიმავალი კავშირი. Outbound Traffic კი არის ტრაფიკი, რომელიც შიდა ქსელიდან გარეთ, მაგალითად Internet-ისკენ მიდის. Firewall-ს შეუძლია ორივე მიმართულების კონტროლი და შესაბამისი წესების მიხედვით მათი დაშვება ან დაბლოკვა.

Firewall-ის წესებში შეიძლება განისაზღვროს, საიდან მოდის კავშირი, სად მიდის, რომელ პროტოკოლს იყენებს და რომელ პორტზე ხდება დაკავშირება. მაგალითად, Firewall-ის წესმა შეიძლება დაუშვას ლოკალური ქსელიდან სერვერის TCP 443 პორტთან დაკავშირება. ამ შემთხვევაში Source იქნება ლოკალური ქსელი, Destination — სერვერი, Protocol — TCP, Port — 443, ხოლო Action — Allow. სხვა შემთხვევაში იგივე კავშირი შეიძლება დაიბლოკოს და Action იყოს Block ან Deny.

Network Security-ში მნიშვნელოვანია იმის ცოდნაც, რომ Firewall და NAT ერთი და იგივე არ არის. NAT ძირითადად IP მისამართებისა და ზოგ შემთხვევაში პორტების თარგმნას ახორციელებს, რათა Private IP მისამართების მქონე მოწყობილობებმა Public IP-ის გამოყენებით შეძლონ Internet-თან დაკავშირება. Firewall კი აკონტროლებს, რომელი ქსელური კავშირი უნდა დაიშვას ან დაიბლოკოს. სახლში გამოყენებულ Router-ში NAT და Firewall ხშირად ერთ მოწყობილობაშია გაერთიანებული, თუმცა მათი ფუნქციები განსხვავებულია.

უსაფრთხოებაში დიდი მნიშვნელობა აქვს ქსელურ პორტებსაც. როგორც უკვე ვიცით, სხვადასხვა ქსელური სერვისი სხვადასხვა პორტს იყენებს. მაგალითად, SSH ჩვეულებრივ იყენებს 22-ე პორტს, DNS — 53-ს, HTTP — 80-ს, ხოლო HTTPS — 443-ს. თუ კონკრეტული სერვისი არ არის საჭირო, მისი ქსელური წვდომის შეზღუდვა ან პორტის დაბლოკვა შეიძლება უსაფრთხოების გაუმჯობესებაში დაგვეხმაროს. თუმცა მხოლოდ პორტის ნომრის დამალვა ან შეცვლა თავისთავად საკმარისი უსაფრთხოების მექანიზმი არ არის.

ქსელის უსაფრთხოებაში ასევე მნიშვნელოვანია Authentication და Authorization. Authentication ნიშნავს მომხმარებლის ან მოწყობილობის იდენტობის დადასტურებას, ანუ პასუხობს კითხვას „ვინ ხარ?“. მაგალითად, მომხმარებელი სისტემაში შედის username-ისა და password-ის გამოყენებით. Authorization კი განსაზღვრავს, რა მოქმედებების შესრულების უფლება აქვს უკვე ავტორიზებულ მომხმარებელს. მაგალითად, ჩვეულებრივ მომხმარებელს შეიძლება ჰქონდეს ფაილის მხოლოდ წაკითხვის უფლება, ხოლო ადმინისტრატორს — მისი შეცვლისა და წაშლის უფლებაც.

კიდევ ერთი მნიშვნელოვანი ცნებაა Encryption, ანუ დაშიფვრა. Encryption-ის დროს მონაცემები გარდაიქმნება ისეთ ფორმაში, რომლის წაკითხვაც შესაბამისი მექანიზმის გარეშე რთული ან შეუძლებელია. მაგალითად, HTTPS უზრუნველყოფს Browser-სა და Web Server-ს შორის დაშიფრულ კავშირს. ამიტომ ქსელში გადაცემული მონაცემების დაცვა შესაძლებელია მათი უბრალო სახით მოსმენისგან.

ქსელის უსაფრთხოებაში ასევე მნიშვნელოვანია ქსელის სწორად დაყოფა. მაგალითად, VLAN-ის საშუალებით შეგვიძლია ერთი ფიზიკური ქსელი რამდენიმე ლოგიკურ ქსელად დავყოთ და სხვადასხვა ტიპის მოწყობილობები ერთმანეთისგან გამოვყოთ. მაგალითად, თანამშრომლების, სერვერებისა და სტუმრების მოწყობილობები შეიძლება სხვადასხვა VLAN-ში განთავსდეს. საჭიროების შემთხვევაში მათ შორის კომუნიკაცია Firewall-ისა და Routing-ის წესებით შეიძლება გაკონტროლდეს.

Network Security მხოლოდ Firewall-ის დაყენებას არ ნიშნავს. უსაფრთხო ქსელში მნიშვნელოვანია ძლიერი Authentication, შესაბამისი Authorization, მონაცემების Encryption, არასაჭირო სერვისებისა და პორტების შეზღუდვა, სისტემებისა და პროგრამების განახლება, ქსელის სწორად დაყოფა და ქსელური ტრაფიკის მონიტორინგი. საბოლოოდ, ქსელის უსაფრთხოების მიზანია, რომ მხოლოდ უფლებამოსილმა მომხმარებლებმა და მოწყობილობებმა მიიღონ საჭირო რესურსებზე წვდომა, ხოლო არასასურველი და საეჭვო კავშირები შესაბამისი წესების მიხედვით შეიზღუდოს.
