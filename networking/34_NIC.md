როდესაც კომპიუტერს ქსელთან დაკავშირება სჭირდება, მას სჭირდება სპეციალური ქსელური ინტერფეისი, რომლის საშუალებითაც შეძლებს მონაცემების გაგზავნასა და მიღებას. სწორედ ამას ეწოდება Network Interface. მოწყობილობა, რომელიც ამ ქსელურ კავშირს უზრუნველყოფს, ცნობილია როგორც NIC (Network Interface Card/Controller). მარტივად რომ ვთქვათ, NIC არის ქსელური ადაპტერი, რომელიც კომპიუტერს საშუალებას აძლევს ქსელში იმუშაოს.

თანამედროვე კომპიუტერებში NIC ხშირად დედაპლატაზეა ინტეგრირებული და ცალკე ბარათის სახით არ გვხვდება. მაგალითად, კომპიუტერს შეიძლება ჰქონდეს ჩაშენებული Ethernet ადაპტერი და ასევე Wi-Fi ადაპტერი. Ethernet-ის შემთხვევაში კომპიუტერი ქსელს ქსელის კაბელით უერთდება, ხოლო Wi-Fi-ის შემთხვევაში კავშირი უსადენოდ, რადიოსიგნალის საშუალებით ხდება. მიუხედავად იმისა, რომ ორივე განსხვავებული ტექნოლოგიაა, ორივე Network Interface-ის როლს ასრულებს.

თითოეულ ქსელურ ინტერფეისს აქვს საკუთარი MAC Address, რომელიც ძირითადად გამოიყენება მონაცემთა გადაცემის Data Link Layer-ზე. როდესაც ინტერფეისს ქსელში IP მისამართიც აქვს მინიჭებული, მას უკვე შეუძლია Layer 3 დონეზე IP კომუნიკაციაში მონაწილეობა. მაგალითად, კომპიუტერის Wi-Fi ინტერფეისს შეიძლება ჰქონდეს MAC მისამართი AA:BB:CC:11:22:33 და IP მისამართი 192.168.1.20, ხოლო Ethernet ინტერფეისს — სხვა MAC და სხვა IP მისამართი.

აქ მნიშვნელოვანია MAC და IP მისამართების განსხვავების გაგება. MAC Address დაკავშირებულია კონკრეტულ ქსელურ ინტერფეისთან და გამოიყენება ლოკალურ ქსელში Ethernet/Wi-Fi კომუნიკაციისთვის, ხოლო IP Address გამოიყენება ქსელებს შორის მოწყობილობის მისამართის განსაზღვრისა და IP კომუნიკაციისთვის. ამიტომ ერთი Network Interface შეიძლება ერთდროულად გვქონდეს წარმოდგენილი როგორც ფიზიკური ქსელური ადაპტერი თავისი MAC Address-ით და ქსელში კონფიგურირებული ინტერფეისი თავისი IP Address-ით.

ოპერაციულ სისტემაში თითოეული ქსელური ადაპტერი ცალკე ინტერფეისად ჩანს. მაგალითად, Windows-ში ipconfig ან ipconfig /all ბრძანებით შეგვიძლია ვნახოთ Ethernet და Wi-Fi ინტერფეისები, მათი IP მისამართები, Subnet Mask, Default Gateway, DNS და სხვა ინფორმაცია. Linux-ში მსგავსი ინფორმაციის სანახავად გამოიყენება ip addr ან ip a.

Network Interface-ის მდგომარეობა განსაკუთრებით მნიშვნელოვანია ქსელის პრობლემების დიაგნოსტიკის დროს. თუ Wi-Fi ადაპტერი გამორთულია, კომპიუტერი Wi-Fi ქსელთან ვერ დაკავშირება. თუ Ethernet კაბელი არ არის დაკავშირებული ან ქსელურ ადაპტერს პრობლემა აქვს, Ethernet ინტერფეისიც შეიძლება არ მუშაობდეს. ასევე შესაძლებელია ინტერფეისი ჩართული იყოს, მაგრამ მას IP მისამართი არ ჰქონდეს, რის გამოც ქსელთან სრულფასოვანი კომუნიკაცია ვერ მოხერხდეს.

ამიტომ, როდესაც მომხმარებელი ამბობს, რომ „ინტერნეტი არ მუშაობს“, System Administrator პირველ რიგში უნდა გაითვალისწინოს არა მხოლოდ ინტერნეტ-კავშირი, არამედ თვითონ Network Interface-იც: ჩართულია თუ არა შესაბამისი ადაპტერი, არის თუ არა დაკავშირებული კაბელი ან Wi-Fi, აქვს თუ არა ინტერფეისს MAC და IP კონფიგურაცია და იღებს თუ არა ის ქსელის საჭირო პარამეტრებს.

საბოლოოდ, NIC არის ქსელური ადაპტერი, რომელიც მოწყობილობას ქსელთან დაკავშირების საშუალებას აძლევს, ხოლო Network Interface არის ის ქსელური ინტერფეისი, რომლის საშუალებითაც ოპერაციული სისტემა ამ კავშირს იყენებს. კომპიუტერს შეიძლება ერთდროულად ჰქონდეს რამდენიმე ინტერფეისი, მაგალითად Ethernet და Wi-Fi, და თითოეულ მათგანს ჰქონდეს საკუთარი MAC Address და შესაბამისი IP კონფიგურაცია.
