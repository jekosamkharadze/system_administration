წარმოიდგინეთ, რომ კომპანიაში ორი Switch ერთმანეთთან ერთი Ethernet კაბელით არის დაკავშირებული. ამ კაბელით ყოველდღიურად უამრავი მონაცემი მოძრაობს — კომპიუტერებიდან, სერვერებიდან, Access Point-ებიდან და სხვა მოწყობილობებიდან. გარკვეული დროის შემდეგ შეიძლება ერთი კავშირი აღარ იყოს საკმარისი და საჭირო გახდეს უფრო დიდი საერთო გამტარუნარიანობა. ამ დროს შეგვიძლია რამდენიმე Ethernet კაბელი გამოვიყენოთ და ისინი ერთ ლოგიკურ კავშირად გავაერთიანოთ. ამ ტექნოლოგიას Link Aggregation ეწოდება.

მაგალითად, თუ ორ Switch-ს შორის ორი Ethernet კაბელი გვაქვს, შეგვიძლია ორივე კაბელი ერთ Link Aggregation ჯგუფში გავაერთიანოთ. გარედან ეს ორი კაბელი ერთ ლოგიკურ კავშირად აღიქმება, თუმცა ფიზიკურად ისევ ორი ცალკე კაბელია. ამ გზით ქსელს შეუძლია ტრაფიკი ამ კავშირებს შორის გადაანაწილოს და ერთი კაბელის გათიშვის შემთხვევაში მეორე კავშირი კვლავ გამოიყენოს.

Link Aggregation-ის მართვისთვის ხშირად გამოიყენება LACP (Link Aggregation Control Protocol). LACP ეხმარება დაკავშირებულ Switch-ებს შეთანხმდნენ, რომელი პორტები უნდა გაერთიანდეს ერთ ჯგუფში და აკონტროლებს ამ კავშირების მდგომარეობას. მაგალითად, თუ Switch A-სა და Switch B-ს შორის ორი შესაბამისი პორტი გვაქვს, LACP-ის საშუალებით ეს პორტები შეიძლება ერთ Aggregated Link-ში გაერთიანდეს.

ამის ერთ-ერთი მთავარი უპირატესობა არის რეზერვირება. თუ ორი კაბელიდან ერთ-ერთი დაზიანდა ან გაითიშა, მეორე შეიძლება კვლავ აგრძელებდეს მუშაობას. შედეგად, ერთი ფიზიკური კავშირის დაკარგვა აუცილებლად არ ნიშნავს Switch-ებს შორის სრული კავშირის დაკარგვას. მეორე უპირატესობაა საერთო გამტარუნარიანობის გაზრდა, რადგან სხვადასხვა ქსელური ტრაფიკი შეიძლება გაერთიანებულ კავშირებში გადანაწილდეს.

თუმცა მნიშვნელოვანია გავიგოთ, რომ ორი 1 Gbps კაბელის გაერთიანება ავტომატურად არ ნიშნავს, რომ ერთი კონკრეტული კავშირის სიჩქარე აუცილებლად 2 Gbps გახდება. ტრაფიკის განაწილება დამოკიდებულია მოწყობილობისა და ქსელის კონფიგურაციაზე. რამდენიმე სხვადასხვა კავშირი შეიძლება სხვადასხვა ფიზიკურ ბმულზე გადანაწილდეს.

მაგალითად, ერთ მომხმარებელს შეიძლება სერვერთან ერთი კავშირი ჰქონდეს, ხოლო სხვა მომხმარებელს — იმავე სერვერთან სხვა კავშირი. Link Aggregation-ის შემთხვევაში ამ სხვადასხვა ტრაფიკის განაწილება შესაძლებელია რამდენიმე ფიზიკურ ბმულზე, რის შედეგადაც მთლიან ქსელს უფრო დიდი შესაძლებლობა აქვს.

ამიტომ Link Aggregation და LACP ერთმანეთისგან ოდნავ განსხვავდება: Link Aggregation არის რამდენიმე ფიზიკური ქსელური კავშირის ერთ ლოგიკურ კავშირად გაერთიანების ტექნოლოგია, ხოლო LACP არის პროტოკოლი, რომელიც ამ გაერთიანების შეთანხმებასა და მართვაში გვეხმარება.

System Administrator-ისთვის ეს განსაკუთრებით მნიშვნელოვანია Switch-ებს შორის, სერვერებთან ან სხვა მნიშვნელოვან ქსელურ მოწყობილობებთან ისეთი კავშირების შექმნისას, სადაც საჭიროა როგორც მეტი საერთო გამტარუნარიანობა, ასევე კავშირის რეზერვირება.

მოკლედ, Link Aggregation რამდენიმე Ethernet კაბელს ერთ ლოგიკურ კავშირად აერთიანებს, ხოლო LACP ამ კავშირის ავტომატურად მართვაში გვეხმარება.
