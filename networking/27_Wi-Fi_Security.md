Wi-Fi Security არის უკაბელო ქსელის დაცვა არასანქცირებული წვდომისგან და ქსელში გადაცემული მონაცემების დაცვის მექანიზმების ერთობლიობა. როდესაც ტელეფონი ან კომპიუტერი Wi-Fi ქსელს უერთდება, მხოლოდ პაროლის ცოდნა არ არის მთავარი — მნიშვნელოვანია, როგორ ხდება მოწყობილობის ავთენტიკაცია და როგორ იშიფრება მონაცემები ქსელში.

SSID არის Wi-Fi ქსელის სახელი, რომელსაც მოწყობილობაში ქსელების ჩამონათვალში ვხედავთ. მაგალითად, თუ როუტერი გვიჩვენებს Home_WiFi, ეს არის მისი SSID. SSID თავისთავად უსაფრთხოების მექანიზმი არ არის. მისი დამალვაც არ ნიშნავს, რომ ქსელი დაცულია, რადგან დამალული SSID-ის აღმოჩენა მაინც შესაძლებელია. უსაფრთხოებას ძირითადად უზრუნველყოფს Authentication და Encryption.

Authentication (ავთენტიკაცია) ნიშნავს იმის შემოწმებას, აქვს თუ არა მოწყობილობას Wi-Fi ქსელთან დაკავშირების უფლება. სახლის Wi-Fi-ში ყველაზე გავრცელებული შემთხვევაა პაროლით დაკავშირება. მაგალითად, როდესაც ტელეფონში ვირჩევთ Home_WiFi-ს და შეგვყავს პაროლი, ქსელი ამოწმებს ჩვენს წვდომას.

Encryption (დაშიფვრა) ნიშნავს მონაცემების ისეთი ფორმით გადაცემას, რომ მათი წაკითხვა მარტივად ვერ შეძლოს მესამე პირმა. მაგალითად, როდესაც ტელეფონი Wi-Fi-ის საშუალებით აგზავნის მონაცემებს, დაცულ ქსელში ეს მონაცემები დაშიფრულია. ამიტომ Wi-Fi-ის უსაფრთხოებაში Authentication და Encryption ერთმანეთისგან განსხვავებული ცნებებია: Authentication პასუხობს კითხვას „აქვს თუ არა მოწყობილობას წვდომა?“, ხოლო Encryption — „როგორ დავიცვათ გადაცემული მონაცემები?“.

Wi-Fi უსაფრთხოებისთვის სხვადასხვა სტანდარტი გამოიყენება. ძველი WEP (Wired Equivalent Privacy) დღეს მოძველებულად და დაუცველად ითვლება და თანამედროვე ქსელში მისი გამოყენება არ არის რეკომენდებული. მის შემდეგ ფართოდ გავრცელდა WPA და WPA2.

WPA2 (Wi-Fi Protected Access 2) დიდი ხნის განმავლობაში იყო Wi-Fi ქსელების ერთ-ერთი ძირითადი უსაფრთხოების სტანდარტი. სახლის ქსელებში ხშირად გვხვდება WPA2-Personal, სადაც მომხმარებელი Wi-Fi-ის პაროლით ერთვება. WPA2 იყენებს ძლიერ კრიპტოგრაფიულ დაცვას მონაცემების დასაშიფრად, თუმცა უსაფრთხოების დონე ასევე დამოკიდებულია პაროლის სიძლიერესა და როუტერის სწორ კონფიგურაციაზე.

WPA3 უფრო ახალი Wi-Fi უსაფრთხოების სტანდარტია, რომელიც WPA2-ის შემდეგ შეიქმნა. WPA3-Personal-ში გამოიყენება SAE (Simultaneous Authentication of Equals), რომელიც პაროლზე დაფუძნებული ავთენტიკაციის პროცესს უფრო დაცულს ხდის. WPA3 ასევე შექმნილია იმისთვის, რომ პაროლის გამოცნობაზე დაფუძნებული ზოგიერთი შეტევის წინააღმდეგ უფრო ძლიერი დაცვა ჰქონდეს.

პრაქტიკაში როუტერის პარამეტრებში შეიძლება შეგვხვდეს ისეთი ვარიანტები, როგორიცაა WPA2-Personal, WPA3-Personal ან WPA2/WPA3 Mixed Mode. Mixed Mode გამოიყენება მაშინ, როდესაც ქსელში არის როგორც WPA2-ის, ასევე WPA3-ის მხარდამჭერი მოწყობილობები.

მაგალითად, გვაქვს როუტერი:

SSID: Home_WiFi
Security: WPA2/WPA3-Personal
Password: ********

აქ Home_WiFi არის ქსელის სახელი, WPA2/WPA3 არის უსაფრთხოების სტანდარტი, ხოლო პაროლი გამოიყენება მოწყობილობის ავთენტიკაციისთვის.

მნიშვნელოვანია ასევე განვასხვავოთ Wi-Fi-ის პაროლი და Encryption. პაროლი არის ის ინფორმაცია, რომელსაც მომხმარებელი შეიყვანს ქსელში შესასვლელად, ხოლო encryption არის კრიპტოგრაფიული მექანიზმი, რომლითაც ქსელში გადაცემული მონაცემები დაცულია. ამიტომ მხოლოდ ძლიერი პაროლის არსებობა არ არის საკმარისი, თუ ქსელი მოძველებულ უსაფრთხოების სტანდარტს იყენებს.

უსაფრთხოების თვალსაზრისით, Open Wi-Fi ქსელს პაროლი საერთოდ არ აქვს და Wi-Fi დონეზე მონაცემების დაცვის მექანიზმი მნიშვნელოვნად სუსტია. ასეთ ქსელში განსაკუთრებით მნიშვნელოვანია ზედა დონის დაშიფვრა, მაგალითად HTTPS.

საბოლოოდ, Wi-Fi უსაფრთხოების ძირითადი იდეა ასეთია: SSID განსაზღვრავს ქსელის სახელს, Authentication ამოწმებს მოწყობილობის წვდომას, ხოლო Encryption იცავს ქსელში გადაცემულ მონაცემებს. WPA2 და განსაკუთრებით WPA3 თანამედროვე Wi-Fi უსაფრთხოების სტანდარტებია, ხოლო WEP მოძველებულია.

სისტემურ ადმინისტრირებაში ეს ცოდნა მნიშვნელოვანია, რადგან როუტერის ან Access Point-ის კონფიგურაციისას უნდა შეგვეძლოს უსაფრთხოების რეჟიმის სწორად არჩევა, ძლიერი პაროლის გამოყენება, არასაჭირო ღია ქსელების თავიდან აცილება და WPA3-ის გამოყენება იქ, სადაც მოწყობილობები მას მხარს უჭერენ.
