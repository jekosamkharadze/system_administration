Network Topology არის ქსელში მოწყობილობების ერთმანეთთან დაკავშირებისა და განლაგების სტრუქტურა. მარტივად რომ ვთქვათ, ტოპოლოგია გვიჩვენებს, როგორ არიან მოწყობილობები ერთმანეთთან დაკავშირებული და როგორ მოძრაობს მონაცემები ქსელში.

ტოპოლოგია შეიძლება განვიხილოთ როგორც Physical Topology და Logical Topology. Physical Topology აღწერს, როგორ არის მოწყობილობები ფიზიკურად დაკავშირებული კაბელებითა და სხვა საშუალებებით, ხოლო Logical Topology აღწერს, როგორ მოძრაობს მონაცემები ქსელში.

Bus Topology:

    Bus Topology-ში ყველა მოწყობილობა დაკავშირებულია ერთ საერთო საკომუნიკაციო ხაზთან, რომელსაც Backbone-ს უწოდებენ. როდესაც ერთი მოწყობილობა აგზავნის მონაცემს, ის საერთო ხაზზე გადაიცემა და შესაბამისი მოწყობილობა იღებს მას.

    მისი უპირატესობაა მარტივი სტრუქტურა და შედარებით მცირე რაოდენობის კაბელის გამოყენება. მინუსია ის, რომ მთავარი კაბელის დაზიანებამ შეიძლება მთელი ქსელის მუშაობა შეაფერხოს. თანამედროვე Ethernet ქსელებში ეს ტოპოლოგია პრაქტიკულად აღარ გამოიყენება.

Star Topology:

    Star Topology-ში ყველა მოწყობილობა სათითაოდ დაკავშირებულია ცენტრალურ მოწყობილობასთან, მაგალითად Switch-თან.

    ეს თანამედროვე LAN ქსელებში ერთ-ერთი ყველაზე გავრცელებული სტრუქტურაა. მისი მთავარი უპირატესობაა ის, რომ ერთი კაბელის ან მოწყობილობის დაზიანება ჩვეულებრივ მხოლოდ კონკრეტულ მოწყობილობას აზიანებს და არა მთელ ქსელს. თუმცა ცენტრალური Switch-ის გათიშვამ შეიძლება მასთან დაკავშირებული მთელი ქსელის მუშაობა შეაფერხოს.

Ring Topology:

    Ring Topology-ში მოწყობილობები ერთმანეთთან რგოლის ფორმით არიან დაკავშირებული. თითოეული მოწყობილობა დაკავშირებულია შემდეგ მოწყობილობასთან და საბოლოოდ იქმნება დახურული წრე.

    მისი გამოყენება დღეს ჩვეულებრივ LAN ქსელებში ნაკლებად გვხვდება.

Mesh Topology:

    Mesh Topology-ში მოწყობილობებს შორის მრავალი პირდაპირი კავშირი არსებობს. Full Mesh-ში თითოეული მოწყობილობა დაკავშირებულია ყველა სხვა მოწყობილობასთან.

    მისი მთავარი უპირატესობაა Redundancy — თუ ერთი კავშირი დაზიანდა, მონაცემებს შეიძლება სხვა გზით გადაეცეს. მინუსია მაღალი ღირებულება და რთული ინფრასტრუქტურა, რადგან ბევრი კავშირის შექმნაა საჭირო.

Tree Topology:

    Tree Topology წარმოადგენს იერარქიულ სტრუქტურას, რომელიც ხშირად Star Topology-ის რამდენიმე ჯგუფის გაერთიანებას ჰგავს. ქსელი იყოფა სხვადასხვა სეგმენტად და ცენტრალური მოწყობილობებიდან ქვედა დონის მოწყობილობებისკენ განშტოებები იქმნება.

    ეს სტრუქტურა ხშირად გამოიყენება დიდ ორგანიზაციებში, სადაც ქსელის სხვადასხვა განყოფილებად დაყოფაა საჭირო.

Hybrid Topology:

    Hybrid Topology რამდენიმე სხვადასხვა ტოპოლოგიის კომბინაციაა. მაგალითად, ერთ ქსელში შეიძლება გამოყენებული იყოს Star და Tree სტრუქტურები ერთად.

    დიდ ქსელებში Hybrid Topology საკმაოდ პრაქტიკულია, რადგან კონკრეტული გარემოსა და მოთხოვნების მიხედვით სხვადასხვა სტრუქტურის გამოყენების საშუალებას იძლევა.

ყველაზე მნიშვნელოვანი:

Bus — ერთი საერთო საკომუნიკაციო ხაზი.

Star — ყველა მოწყობილობა ცენტრალურ მოწყობილობას უკავშირდება.

Ring — მოწყობილობები რგოლის სახით არიან დაკავშირებული.

Mesh — მრავალი ურთიერთდაკავშირებული გზა.

Tree — იერარქიული, განშტოებული სტრუქტურა.

Hybrid — რამდენიმე ტოპოლოგიის კომბინაცია.

დასკვნა: Network Topology განსაზღვრავს, როგორ არის ქსელის მოწყობილობები ერთმანეთთან დაკავშირებული და როგორ არის ორგანიზებული ქსელი. თანამედროვე LAN ქსელებში ყველაზე გავრცელებულია Star Topology, ხოლო უფრო დიდ და რთულ ინფრასტრუქტურებში ხშირად გვხვდება Tree და Hybrid სტრუქტურები. ქსელის ტოპოლოგიის არჩევა დამოკიდებულია მის ზომაზე, ღირებულებაზე, საიმედოობის მოთხოვნებზე და გამოყენების მიზანზე.
