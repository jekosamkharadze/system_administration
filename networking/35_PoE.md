ქსელში ჩვეულებრივ Ethernet კაბელს მონაცემების გადასაცემად ვიყენებთ, თუმცა არსებობს ტექნოლოგია, რომლის საშუალებითაც იმავე კაბელით შესაძლებელია მოწყობილობისთვის ელექტროენერგიის მიწოდებაც. სწორედ ამას ეწოდება PoE (Power over Ethernet). მისი მთავარი იდეა ის არის, რომ ერთი Ethernet კაბელი ერთდროულად გამოიყენება როგორც მონაცემების გადასაცემად, ასევე ელექტროენერგიის მისაწოდებლად.

მაგალითად, წარმოვიდგინოთ ოფისში დამონტაჟებული Wi-Fi Access Point. ჩვეულებრივ მას ქსელთან დასაკავშირებლად Ethernet კაბელი სჭირდება, ხოლო ელექტროენერგიისთვის ცალკე კვების ადაპტერი. PoE-ის გამოყენების შემთხვევაში შესაძლებელია მხოლოდ ერთი Ethernet კაბელის მიყვანა. კაბელით Access Point ერთდროულად იღებს ქსელურ მონაცემებსაც და ელექტროენერგიასაც. იგივე პრინციპი ხშირად გამოიყენება IP კამერებსა და VoIP ტელეფონებში.

PoE-ის დროს ელექტროენერგიის მიმწოდებელ მოწყობილობას ეწოდება PSE (Power Sourcing Equipment), ხოლო ენერგიის მიმღებ მოწყობილობას — PD (Powered Device). მაგალითად, PoE Switch შეიძლება იყოს PSE, ხოლო IP კამერა — PD. Switch ქსელურ მონაცემებსაც აგზავნის კამერისკენ და საჭიროების შემთხვევაში ელექტროენერგიასაც აწვდის.

ყველა Ethernet მოწყობილობა ავტომატურად არ ნიშნავს PoE-ს მხარდაჭერას. თუ ჩვეულებრივ Switch-ს შევაერთებთ მოწყობილობასთან, რომელსაც კვება სჭირდება, მხოლოდ Ethernet კაბელის შეერთება საკმარისი არ იქნება, თუ Switch-ს PoE მხარდაჭერა არ აქვს ან სხვა შესაბამისი PoE მოწყობილობა არ გამოიყენება.

PoE განსაკუთრებით მოსახერხებელია იმ შემთხვევებში, როდესაც მოწყობილობისთვის ცალკე ელექტრო კაბელის გაყვანა რთულია. მაგალითად, შენობაში შეიძლება Wi-Fi Access Point ჭერზე იყოს დამონტაჟებული. იქ ცალკე დენის წყაროს მიყვანა რთული იყოს, მაგრამ Ethernet კაბელი ქსელური Switch-იდან უკვე შეიძლება მიდიოდეს. PoE-ის გამოყენებით იგივე კაბელი საკმარისი ხდება.

PoE ხშირად გამოიყენება Wi-Fi Access Point-ებში, IP კამერებში, VoIP ტელეფონებში, ზოგიერთი ტიპის ქსელურ მოწყობილობასა და სხვა დაბალი სიმძლავრის მოწყობილობებში. System Administrator-ისთვის PoE მნიშვნელოვანია, რადგან ქსელის დაგეგმვისას საჭიროა გაითვალისწინოს არა მხოლოდ ის, აქვს თუ არა Switch-ს საკმარისი ქსელური პორტები, არამედ აქვს თუ არა საჭირო პორტებს PoE მხარდაჭერა და შეუძლია თუ არა მათ დაკავშირებული მოწყობილობებისთვის საჭირო სიმძლავრის მიწოდება.

მოკლედ, PoE ნიშნავს Ethernet კაბელის საშუალებით ერთდროულად მონაცემებისა და ელექტროენერგიის გადაცემას. ამის გამო მოწყობილობისთვის ცალკე ქსელური და კვების კაბელის გამოყენება ყოველთვის საჭირო აღარ არის.
