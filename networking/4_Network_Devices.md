ქსელური მოწყობილობები არის Hardware კომპონენტები, რომლებიც კომპიუტერებსა და სხვა მოწყობილობებს ქსელში ერთმანეთთან აკავშირებენ, მონაცემების გადაცემას უზრუნველყოფენ და სხვადასხვა ქსელებს შორის კომუნიკაციას მართავენ. თითოეულ მოწყობილობას განსხვავებული დანიშნულება აქვს. NIC (Network Interface Controller) არის კომპონენტი, რომლის საშუალებითაც კონკრეტული მოწყობილობა ქსელს უერთდება. ის შეიძლება იყოს Ethernet ან Wi-Fi ტიპის და აქვს MAC Address, რომელიც Network Interface-ის იდენტიფიცირებისთვის გამოიყენება. NIC-ის გარეშე კომპიუტერი ჩვეულებრივ ვერ შეძლებს შესაბამის ქსელურ კავშირს.

Hub არის ძველი და მარტივი ქსელური მოწყობილობა, რომელიც რამდენიმე მოწყობილობას ერთმანეთთან აერთიანებს. როდესაც Hub ერთ პორტზე იღებს მონაცემს, ის მონაცემს ყველა სხვა პორტზე ავრცელებს, რადგან ვერ განსაზღვრავს, კონკრეტულად რომელ მოწყობილობას ეკუთვნის მონაცემი. Hub მუშაობს OSI Model-ის Physical Layer-ზე და თანამედროვე ქსელებში თითქმის აღარ გამოიყენება, რადგან ის Switch-მა ჩაანაცვლა. მისი მთავარი ნაკლია ზედმეტი Traffic და Collision-ების წარმოქმნის შესაძლებლობა.

Switch Hub-ის უფრო განვითარებული მოწყობილობაა და გამოიყენება ძირითადად ერთ LAN-ში არსებული მოწყობილობების დასაკავშირებლად. Switch სწავლობს, რომელი MAC Address რომელ პორტზეა დაკავშირებული და ამის საფუძველზე მონაცემებს შესაბამის პორტზე აგზავნის, ნაცვლად იმისა, რომ ყველა პორტზე გაავრცელოს. მაგალითად, თუ PC1-ს PC3-სთვის აქვს მონაცემი გასაგზავნი, Switch განსაზღვრავს PC3-ის პორტს და მონაცემს ძირითადად მხოლოდ იმ მიმართულებით აგზავნის. Switch-ები შეიძლება იყოს Unmanaged ან Managed. Managed Switch-ის კონფიგურაცია შესაძლებელია და მას შეიძლება ჰქონდეს VLAN, უსაფრთხოების, Traffic-ის კონტროლისა და სხვა ფუნქციები.

Router გამოიყენება სხვადასხვა ქსელების ერთმანეთთან დასაკავშირებლად და მონაცემთა პაკეტების ერთი ქსელიდან მეორეში გადასამისამართებლად. Switch ძირითადად MAC Address-ების გამოყენებით მუშაობს ერთ LAN-ში, ხოლო Router IP Address-ებსა და Routing-ს იყენებს იმის დასადგენად, რომელ ქსელში და რა მიმართულებით უნდა წავიდეს მონაცემი. მაგალითად, როდესაც სახლში არსებული კომპიუტერი Internet-ს უკავშირდება, მონაცემები შეიძლება მოძრაობდეს ასე: PC → Switch/Wi-Fi → Router → ISP → Internet. Router-ს ასევე შეიძლება ჰქონდეს NAT, DHCP, Firewall, VPN და სხვა ფუნქციები.

Access Point (AP) არის მოწყობილობა, რომელიც Wireless მოწყობილობებს ქსელთან Wi-Fi-ის საშუალებით აკავშირებს. მაგალითად, Laptop ან Smartphone Wi-Fi-ით უკავშირდება Access Point-ს, ხოლო Access Point Ethernet კაბელით შეიძლება დაკავშირებული იყოს Switch-თან. Access Point-ის მთავარი დანიშნულება Wi-Fi Access-ის უზრუნველყოფაა, ხოლო Router-ის მთავარი ფუნქცია Routing-ია. თუმცა სახლის Wi-Fi Router-ში Router, Switch და Access Point-ის ფუნქციები ხშირად ერთ მოწყობილობაშია გაერთიანებული.

Modem არის მოწყობილობა, რომელიც კონკრეტული ტიპის Internet Connection-ის შემთხვევაში ადგილობრივ ქსელს ISP-ის ინფრასტრუქტურასთან აკავშირებს. მისი ფუნქცია დამოკიდებულია გამოყენებულ ტექნოლოგიაზე, მაგალითად DSL, Cable ან Cellular კავშირზე. Modem და Router განსხვავებული მოწყობილობებია: Modem უზრუნველყოფს ISP-სთან შესაბამის კავშირს, ხოლო Router სხვადასხვა ქსელებს შორის მონაცემების გადამისამართებას. თანამედროვე სახლის მოწყობილობებში ეს ფუნქციები ხშირად ერთ მოწყობილობაშია გაერთიანებული.

Repeater გამოიყენება ქსელური სიგნალის მოქმედების არეალის გასაფართოებლად. ის იღებს არსებულ სიგნალს და ხელახლა გადასცემს მას უფრო შორ მანძილზე. მაგალითად, Wi-Fi Repeater შეიძლება გამოიყენო ისეთ ადგილას, სადაც Router-ის Wi-Fi სიგნალი სუსტია. Repeater-ის მთავარი განსხვავება Router-ისგან ისაა, რომ მისი ძირითადი დანიშნულება ქსელებს შორის Routing კი არა, არსებული კავშირის დაფარვის გაფართოებაა.

ამრიგად, NIC მოწყობილობას ქსელთან აკავშირებს, Hub მიღებულ მონაცემს ყველა პორტზე ავრცელებს, Switch მოწყობილობებს ერთ LAN-ში აერთიანებს და მონაცემებს MAC Address-ის მიხედვით შესაბამის პორტზე აგზავნის, Router სხვადასხვა ქსელებს აკავშირებს და IP Address-ის მიხედვით ახორციელებს Routing-ს, Access Point უზრუნველყოფს Wi-Fi კავშირს, Modem კონკრეტული ტიპის კავშირით ISP-სთან დაკავშირებას უზრუნველყოფს, ხოლო Repeater ქსელის სიგნალის დაფარვის გაფართოებას ემსახურება.

ძირითადი:
    Modem — ISP-თან კავშირი.
    Router — სხვადასხვა ქსელებს შორის Routing.
    Switch — ოფისის LAN-ში მოწყობილობების დაკავშირება.
    Access Point — Wi-Fi მოწყობილობების LAN-ში შემოყვანა.
    NIC — თითოეულ მოწყობილობას ქსელთან კავშირის საშუალება.
    Repeater — საჭიროების შემთხვევაში კავშირის დაფარვის გაფართოება.
    Hub — ძველი ტექნოლოგია, რომელიც თანამედროვე ქსელებში ძირითადად Switch-მა ჩაანაცვლა.
