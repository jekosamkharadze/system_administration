კომპიუტერული ქსელი (Computer Network) არის ორი ან მეტი მოწყობილობის ერთმანეთთან დაკავშირებული სისტემა, რომლის საშუალებითაც ისინი ერთმანეთს მონაცემებსა და რესურსებს უზიარებენ.

ქსელში მოწყობილობებს შორის მონაცემები გადაიცემა კაბელით ან უსადენოდ. კაბელური ქსელისთვის ხშირად გამოიყენება Ethernet, ხოლო უსადენო კავშირისთვის — Wi-Fi.

ქსელის მთავარი მიზანია მოწყობილობებს შორის Communication, ანუ კომუნიკაცია. მაგალითად, ერთ კომპიუტერს შეუძლია მეორე კომპიუტერისთვის ფაილის გაგზავნა, რამდენიმე კომპიუტერმა შეიძლება გამოიყენოს ერთი Printer, ხოლო მოწყობილობებს შეუძლიათ Internet-ზე გასვლა.

ქსელში მონაცემები უბრალოდ ჰაერში ან კაბელში უწესრიგოდ არ მოძრაობს. მათ გადასაცემად გამოიყენება Network Protocols, ანუ წესების ერთობლიობა, რომელიც განსაზღვრავს, როგორ უნდა მოხდეს მონაცემების გაგზავნა, მიღება და დამუშავება.

მაგალითად, ინტერნეტში მნიშვნელოვანი პროტოკოლებია TCP/IP, ხოლო Web-ისთვის გამოიყენება HTTP/HTTPS.

ქსელში მოწყობილობის იდენტიფიცირებისთვის სხვადასხვა მისამართი გამოიყენება. ერთ-ერთი ყველაზე მნიშვნელოვანი არის IP Address, რომელიც მოწყობილობის ლოგიკურ მისამართს წარმოადგენს. ასევე არსებობს MAC Address, რომელიც Network Interface-ს უკავშირდება.


ქსელში სხვადასხვა მოწყობილობას განსხვავებული ფუნქცია აქვს. Switch ძირითადად ერთ ლოკალურ ქსელში მოწყობილობებს ერთმანეთთან აკავშირებს, Router კი სხვადასხვა ქსელებს შორის მონაცემების გადამისამართებას ახორციელებს. Access Point უსადენო მოწყობილობებს ქსელთან Wi-Fi-ის საშუალებით აკავშირებს, ხოლო Server ქსელში სხვადასხვა სერვისსა და რესურსს აწვდის სხვა მოწყობილობებს.

ქსელები ერთმანეთისგან განსხვავდება ზომითა და დანიშნულებით. მცირე ქსელი შეიძლება რამდენიმე მოწყობილობისგან შედგებოდეს სახლში, ხოლო დიდი ქსელი მოიცავდეს მთელ ორგანიზაციას ან რამდენიმე გეოგრაფიულ ტერიტორიას. ამ განსხვავების მიხედვით არსებობს LAN, WAN, MAN, PAN და სხვა ტიპის ქსელები.

ქსელები შეიძლება იყოს როგორც პატარა, მაგალითად სახლში რამდენიმე მოწყობილობისგან შემდგარი ქსელი, ასევე ძალიან დიდი — მაგალითად, მთელი Internet, რომელიც ერთმანეთთან დაკავშირებული უზარმაზარი რაოდენობის ქსელებისგან შედგება.

დასკვნა: კომპიუტერული ქსელი არის ერთმანეთთან დაკავშირებული მოწყობილობების სისტემა, რომელიც მათ შორის მონაცემებისა და რესურსების გაცვლის საშუალებას იძლევა. ქსელის მუშაობისთვის საჭიროა მოწყობილობები, კავშირის საშუალებები და შესაბამისი Network Protocols.
