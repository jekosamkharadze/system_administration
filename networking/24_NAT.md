NAT (Network Address Translation) არის ტექნოლოგია, რომლის საშუალებითაც Router ცვლის ქსელურ მისამართებს პაკეტების გადაადგილების დროს. NAT-ის ერთ-ერთი მთავარი დანიშნულებაა, რომ ლოკალურ ქსელში არსებული მრავალი მოწყობილობა ერთი Public IP მისამართის გამოყენებით დაუკავშირდეს ინტერნეტს.

მაგალითად, სახლში შეიძლება გვქონდეს რამდენიმე მოწყობილობა:

ტელეფონი — 192.168.1.10
ლეპტოპი — 192.168.1.11
კომპიუტერი — 192.168.1.12

ეს მისამართები არის Private IP-ები და ინტერნეტში პირდაპირ გლობალურად არ გამოიყენება. სახლის Router-ს კი ინტერნეტ-პროვაიდერისგან შეიძლება ჰქონდეს ერთი Public IP. NAT სწორედ Router-ზე ასრულებს Private IP-ებისა და Public IP-ის შორის თარგმნას.

მაგალითად, ლეპტოპი ინტერნეტში აგზავნის მოთხოვნას. პაკეტი თავდაპირველად შეიძლება გამოიყურებოდეს ასე:

192.168.1.11 → Internet Server

Router პაკეტს ინტერნეტში გაგზავნისას Private IP-ს თავისი Public IP-ით ანაცვლებს:

Public IP → Internet Server

როდესაც პასუხი უკან მოდის, Router-ს უნდა იცოდეს, რომელ შიდა მოწყობილობას ეკუთვნის ეს პასუხი. ამისთვის NAT იყენებს შესაბამის ჩანაწერებს და პასუხს ისევ იმ მოწყობილობას უბრუნებს, რომელმაც მოთხოვნა გაგზავნა.

მაგალითად:

Laptop
192.168.1.11
      ↓
    Router
NAT: Private → Public
      ↓
Public IP
      ↓
   Internet
      ↓
Web Server

თუ სახლში ერთდროულად რამდენიმე მოწყობილობა იყენებს ინტერნეტს, Router NAT-ის საშუალებით მათ კავშირებს ერთმანეთისგან არჩევს. ამისთვის პრაქტიკაში ხშირად გამოიყენება PAT (Port Address Translation), რომელსაც ზოგჯერ „NAT Overload“-საც უწოდებენ. ამ შემთხვევაში რამდენიმე Private IP-ის მქონე მოწყობილობას შეუძლია ერთი Public IP-ის გამოყენება სხვადასხვა Source Port-ის საშუალებით.

მაგალითად, შეიძლება ერთდროულად არსებობდეს:

192.168.1.10:5001 → Public_IP:30001
192.168.1.11:5002 → Public_IP:30002
192.168.1.12:5003 → Public_IP:30003

ამგვარად Router-ს შეუძლია გაარჩიოს, რომელი პასუხი რომელ შიდა მოწყობილობას ეკუთვნის.

NAT-ის გამო ინტერნეტიდან შიდა Private IP მოწყობილობებთან კავშირის დაწყება ჩვეულებრივ პირდაპირ არ ხდება. თუ საჭიროა, რომ ინტერნეტიდან კონკრეტულ შიდა მოწყობილობასთან მივიდეს კავშირი, Router-ზე შეიძლება შეიქმნას Port Forwarding წესი. მაგალითად, შეიძლება კონკრეტული TCP პორტი Router-ის Public IP-ზე გადამისამართდეს შიდა სერვერის IP მისამართზე.

NAT და Firewall ერთი და იგივე არ არის. NAT ძირითადად მისამართებისა და ხშირად პორტების თარგმნას უზრუნველყოფს, ხოლო Firewall განსაზღვრავს, რომელი ქსელური კავშირი უნდა დაიშვას ან დაიბლოკოს. თუმცა სახლის Router-ში ეს ფუნქციები ხშირად ერთ მოწყობილობაშია გაერთიანებული.

მოკლედ, NAT არის ტექნოლოგია, რომელიც Router-ს საშუალებას აძლევს Private IP-ების მქონე მოწყობილობების ტრაფიკი Public IP-ის გამოყენებით ინტერნეტში გადაიტანოს და დაბრუნებული პასუხები შესაბამის შიდა მოწყობილობებს დაუბრუნოს. სახლში არსებული მრავალი მოწყობილობის ერთი Public IP-ით ინტერნეტში მუშაობისას ხშირად გამოიყენება PAT, რომელიც კავშირების გასარჩევად პორტებსაც იყენებს.
