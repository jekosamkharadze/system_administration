Operating System (OS), ანუ ოპერაციული სისტემა, არის სისტემური პროგრამული უზრუნველყოფა, რომელიც მართავს კომპიუტერის Hardware-სა და Software-ს და ქმნის გარემოს, სადაც მომხმარებელსა და პროგრამებს კომპიუტერთან მუშაობა შეუძლიათ. მარტივად რომ ვთქვათ, ოპერაციული სისტემა არის შუამავალი მომხმარებელს, პროგრამებსა და კომპიუტერის ფიზიკურ რესურსებს შორის.

როდესაც კომპიუტერს ვიყენებთ, ჩვენ პირდაპირ CPU-ს, RAM-ს, SSD-ს ან სხვა მოწყობილობებს არ ვმართავთ. მაგალითად, როდესაც ბრაუზერს ვხსნით, ბრაუზერი თავად არ წყვეტს, რომელ RAM-ის მისამართში შეინახოს მონაცემები ან როგორ წაიკითხოს ფაილი SSD-დან. ამ ყველაფერში ოპერაციული სისტემა მონაწილეობს და საჭირო რესურსებს პროგრამას აწვდის.

ოპერაციული სისტემის მთავარი ამოცანაა სისტემის რესურსების მართვა. ეს რესურსებია CPU, RAM, Storage, ქსელური და სხვა მოწყობილობები. OS განსაზღვრავს, რომელ პროგრამას რამდენი რესურსი მიეცეს და როგორ მოხდეს მათი უსაფრთხოდ და ორგანიზებულად გამოყენება.

ოპერაციული სისტემა ასევე მართავს პროგრამების შესრულებას. როდესაც პროგრამას ვუშვებთ, OS ქმნის მისთვის Process-ს, გამოყოფს საჭირო მეხსიერებას, აძლევს CPU-ს გამოყენების შესაძლებლობას და აკონტროლებს მის მუშაობას. ამიტომ პროგრამის გაშვების უკან მხოლოდ პროგრამის კოდი კი არა, ოპერაციული სისტემის მიერ შესრულებული მრავალი მოქმედებაც დგას.

OS ასევე უზრუნველყოფს ფაილებთან მუშაობას. მომხმარებელი ხედავს ფაილებსა და საქაღალდეებს, მაგრამ მათი შენახვა დისკზე უფრო რთული პროცესია. ოპერაციული სისტემა File System-ის საშუალებით მართავს იმას, სად და როგორ ინახება მონაცემები, როგორ ხდება მათი წაკითხვა და ჩაწერა და ვის აქვს კონკრეტულ ფაილზე წვდომის უფლება.

კიდევ ერთი მნიშვნელოვანი ფუნქციაა Hardware-ის მართვა. მაგალითად, როდესაც კლავიატურაზე ღილაკს ვაჭერთ, ოპერაციულმა სისტემამ უნდა მიიღოს ეს ინფორმაცია. როდესაც ფაილს SSD-დან ვკითხულობთ, OS-ს უნდა შეეძლოს Storage მოწყობილობასთან კომუნიკაცია. ამისთვის გამოიყენება Device Drivers და სხვა სისტემური კომპონენტები.

ოპერაციული სისტემა ასევე უზრუნველყოფს უსაფრთხოებას. ერთი პროგრამა არ უნდა შეძლოს სხვა პროგრამის მეხსიერებაში თავისუფლად ჩარევა ან სისტემური რესურსების თვითნებურად შეცვლა. OS იყენებს უფლებებს, პროცესების იზოლაციას, User Mode-სა და Kernel Mode-ს და სხვა მექანიზმებს, რათა სისტემის სხვადასხვა ნაწილი ერთმანეთისგან დაიცვას.

ოპერაციული სისტემის მუშაობა შეგვიძლია მარტივი ჯაჭვით წარმოვიდგინოთ:

**User → Application → Operating System → Hardware**

მაგალითად, მომხმარებელი ხსნის ვიდეოფაილს. ვიდეოპლეერი არის Application. ის OS-ს სთხოვს ფაილის წაკითხვას. OS File System-ის საშუალებით პოულობს ფაილს და Storage მოწყობილობასთან ურთიერთქმედებს. შემდეგ მიღებული მონაცემები პროგრამას უბრუნდება და პროგრამა მათ ეკრანზე გამოსახავს.

თანამედროვე ოპერაციული სისტემის მაგალითებია Windows, Linux, macOS, Android და iOS. მათი შიდა არქიტექტურა და შესაძლებლობები განსხვავდება, მაგრამ ყველა მათგანს საერთო ძირითადი მიზანი აქვს — Hardware-ისა და Software-ის მართვა და პროგრამებისთვის მუშაობის გარემოს შექმნა.

ოპერაციული სისტემა შეგვიძლია წარმოვიდგინოთ როგორც კომპიუტერის მენეჯერი. Hardware არის რესურსი, Application არის პროგრამა, რომელსაც ეს რესურსი სჭირდება, ხოლო OS აკონტროლებს, როგორ და რა პირობებში მიიღებს პროგრამა ამ რესურსს.

მოკლედ, Operating System არის სისტემის ძირითადი პროგრამული ფენა, რომელიც მართავს კომპიუტერის რესურსებს, ასრულებს პროგრამებს, მართავს ფაილებსა და მოწყობილობებს, უზრუნველყოფს უსაფრთხოებას და მომხმარებელსა და პროგრამებს Hardware-თან მუშაობის საშუალებას აძლევს.
