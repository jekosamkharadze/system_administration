Operating System Architecture არის ოპერაციული სისტემის შიდა სტრუქტურა, რომელიც განსაზღვრავს, როგორ არის მისი კომპონენტები ორგანიზებული და როგორ ურთიერთქმედებენ ისინი ერთმანეთთან. არქიტექტურა განსაზღვრავს, სად სრულდება კონკრეტული ფუნქციები, როგორ ხდება აპლიკაციებიდან აპარატურამდე მოთხოვნების გადაცემა და როგორ იმართება სისტემის რესურსები.

ოპერაციული სისტემა ერთი მთლიანობის სახით მუშაობს, თუმცა მის შიგნით ბევრი განსხვავებული კომპონენტია. მაგალითად, პროცესების მართვა აკონტროლებს პროგრამების შესრულებას, მეხსიერების მართვა ანაწილებს RAM-ს, ფაილური სისტემა მართავს ფაილებთან დაკავშირებულ ოპერაციებს, ხოლო მოწყობილობის დრაივერები ოპერაციულ სისტემასა და აპარატურას შორის ურთიერთქმედებას უზრუნველყოფს. არქიტექტურა განსაზღვრავს, როგორ არის ეს კომპონენტები ერთმანეთთან დაკავშირებული.

ოპერაციული სისტემის არქიტექტურაში განსაკუთრებული მნიშვნელობა აქვს Kernel-ს. Kernel სისტემის ცენტრალური ნაწილია, რომელიც პროცესორის, მეხსიერებისა და სხვა მნიშვნელოვანი რესურსების მართვაში მონაწილეობს. აპლიკაციები, ჩვეულებრივ, პირდაპირ ვერ ასრულებენ პრივილეგირებულ აპარატურულ ოპერაციებს. ისინი შესაბამის მოთხოვნებს System Call-ების საშუალებით გადასცემენ ოპერაციულ სისტემას, რის შემდეგაც Kernel საჭირო მოქმედებას ასრულებს ან მართავს.

ოპერაციული სისტემის არქიტექტურის ერთ-ერთი მნიშვნელოვანი საკითხია, როგორ ნაწილდება ფუნქციები Kernel-სა და სხვა კომპონენტებს შორის. ზოგი არქიტექტურა ბევრ სერვისს Kernel-ის სივრცეში ათავსებს, ზოგი კი მეტ ფუნქციას ცალკეულ, იზოლირებულ პროცესებში ანაწილებს. ამ განსხვავებას გავლენა აქვს სისტემის წარმადობაზე, საიმედოობასა და უსაფრთხოებაზე.

არსებობს ოპერაციული სისტემების რამდენიმე ძირითადი არქიტექტურული მიდგომა: Monolithic Kernel, Microkernel და Hybrid Kernel. Monolithic Kernel-ში ბევრი ძირითადი სერვისი Kernel-ის სივრცეში მუშაობს. Microkernel-ში Kernel მინიმალურ ფუნქციებს ინარჩუნებს, ხოლო ბევრი სერვისი მის გარეთ სრულდება. Hybrid Kernel კი ამ მიდგომების გარკვეულ ელემენტებს აერთიანებს.

მაგალითად, Linux-ის Kernel, ძირითადად, მონოლითურ არქიტექტურას იყენებს, თუმცა მოდულების ჩატვირთვასაც უჭერს მხარს. Windows-ის თანამედროვე NT არქიტექტურას ხშირად ჰიბრიდულს უწოდებენ, თუმცა ისიც შეიცავს მონოლითური და მიკროკერნელის მსგავსი მიდგომების ელემენტებს.

ამრიგად, OS Architecture გვიხსნის, როგორ არის ოპერაციული სისტემა შიგნიდან მოწყობილი და როგორ თანამშრომლობენ მისი კომპონენტები. ამ სტრუქტურის ცოდნა გვეხმარება გავიგოთ, რატომ განსხვავდებიან ოპერაციული სისტემები წარმადობით, უსაფრთხოებითა და საიმედოობით.
