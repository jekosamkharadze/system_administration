Monolithic Kernel არის ოპერაციული სისტემის არქიტექტურა, რომელშიც მრავალი ძირითადი სისტემური სერვისი და ფუნქცია Kernel-ის სივრცეში მუშაობს. ეს ნიშნავს, რომ პროცესების მართვა, მეხსიერების მართვა, ფაილურ სისტემასთან დაკავშირებული ფუნქციები და მოწყობილობის დრაივერების დიდი ნაწილი ბირთვის პრივილეგირებულ გარემოში სრულდება.

როგორც ვიცით, Kernel ოპერაციული სისტემის ცენტრალური ნაწილია. მონოლითურ არქიტექტურაში Kernel მხოლოდ პროცესორისა და მეხსიერების მართვით არ შემოიფარგლება — მასში შეიძლება განთავსებული იყოს ქსელის სტეკიც, ფაილური სისტემების კოდი და სხვა სისტემური კომპონენტები. ეს კომპონენტები ერთმანეთს უშუალოდ, Kernel-ის შიგნით არსებული მექანიზმებით უკავშირდება.

მაგალითად, როდესაც პროგრამა ფაილის წაკითხვას ითხოვს, მოთხოვნა System Call-ის საშუალებით ოპერაციულ სისტემას გადაეცემა. შემდეგ Kernel-ის შესაბამისი კომპონენტები ამუშავებენ მოთხოვნას, ფაილური სისტემის კოდი განსაზღვრავს, როგორ უნდა მოიძებნოს საჭირო მონაცემები, ხოლო მოწყობილობის შესაბამისი კოდი საჭიროების შემთხვევაში დისკთან ურთიერთქმედებას უზრუნველყოფს. მონოლითურ არქიტექტურაში ეს კომპონენტები შეიძლება ერთი და იმავე Kernel-ის სივრცეში მუშაობდნენ.

მონოლითური Kernel-ის ერთ-ერთი უპირატესობა წარმადობაა. რადგან კომპონენტები ბირთვის სივრცეში მუშაობენ, მათ შორის კომუნიკაციას ხშირად ნაკლები დამატებითი ხარჯი აქვს, ვიდრე იმ არქიტექტურებში, სადაც სერვისები ცალკეულ პროცესებშია განაწილებული. თუმცა რეალური წარმადობა კონკრეტულ იმპლემენტაციასა და სამუშაო დატვირთვაზეა დამოკიდებული.

ამ არქიტექტურას გარკვეული რისკებიც ახლავს. Kernel-ის სივრცეში არსებული შეცდომიანი კომპონენტი შეიძლება მთლიანი სისტემის სტაბილურობაზე აისახოს. მაგალითად, თუ ბირთვის სივრცეში მომუშავე დრაივერი კრიტიკულ შეცდომას გამოიწვევს, შესაძლოა ოპერაციული სისტემა გაითიშოს ან ავარიულ მდგომარეობაში გადავიდეს. ასევე, Kernel-ის დიდი და რთული კოდის ბაზის უსაფრთხოდ შენარჩუნება მნიშვნელოვან საინჟინრო სამუშაოს მოითხოვს.

მონოლითური არქიტექტურის ცნობილი მაგალითია Linux Kernel. Linux მონოლითურ ბირთვს იყენებს, თუმცა მოდულურია იმ გაგებით, რომ გარკვეული ფუნქციებისა და დრაივერების Kernel Modules-ის სახით ჩატვირთვა და გამორთვა შესაძლებელია. ამიტომ მონოლითური არ ნიშნავს, რომ ყველა კომპონენტი აუცილებლად ერთ ფაილშია მოთავსებული ან რომ სისტემა მოდულებს არ იყენებს.

ამრიგად, Monolithic Kernel არის არქიტექტურა, რომელშიც ოპერაციული სისტემის მრავალი მნიშვნელოვანი კომპონენტი Kernel-ის სივრცეში მუშაობს. ის ეფექტიან კომუნიკაციასა და კარგ წარმადობას უწყობს ხელს, თუმცა ბირთვის სივრცეში არსებული შეცდომები შეიძლება მთელი სისტემისთვის სერიოზული პრობლემა გახდეს.
