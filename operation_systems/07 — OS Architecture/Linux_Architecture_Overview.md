Linux Architecture აღწერს, როგორ არის Linux-ის ოპერაციული სისტემა ორგანიზებული და როგორ თანამშრომლობენ მისი კომპონენტები აპლიკაციების გასაშვებად, აპარატურის სამართავად და სისტემის დასაცავად. Linux ფართოდ გამოიყენება სერვერებში, პერსონალურ კომპიუტერებში, ჩაშენებულ მოწყობილობებსა და სხვა სისტემებში.

Linux-ის არქიტექტურა შეიძლება რამდენიმე ძირითად ფენად წარმოვიდგინოთ. ყველაზე ქვედა ფენაზე არის Hardware — კომპიუტერის ფიზიკური კომპონენტები, მაგალითად, პროცესორი, RAM, დისკი და ქსელური ადაპტერი. მათ ზემოთ მუშაობს Linux Kernel, რომელიც აპარატურასა და პროგრამულ უზრუნველყოფას შორის მთავარ შუამავალს წარმოადგენს.

Linux Kernel პროცესებსა და ნაკადებს მართავს, ანაწილებს მეხსიერებას, ამუშავებს სისტემურ გამოძახებებს (System Calls), უზრუნველყოფს ქსელურ ფუნქციებს და კოორდინირებს მოწყობილობებთან დაკავშირებულ ოპერაციებს. ის ასევე შეიცავს ფაილური სისტემის მხარდაჭერას და მოწყობილობის დრაივერებს. Linux-ის Kernel მონოლითური არქიტექტურისაა, თუმცა მხარს უჭერს ჩასატვირთ მოდულებს, რაც გარკვეული ფუნქციების საჭიროებისამებრ დამატების საშუალებას იძლევა.

Kernel-ის ზემოთ მუშაობს System Libraries — ბიბლიოთეკები, რომლებიც პროგრამებს სისტემურ ფუნქციებთან ურთიერთქმედების მოსახერხებელ ინტერფეისს აძლევს. მაგალითად, Linux-ში C პროგრამები ხშირად იყენებს glibc-ს. ბიბლიოთეკა შეიძლება სისტემურ გამოძახებებს იყენებდეს, რათა პროგრამამ ფაილებთან, პროცესებთან ან მეხსიერებასთან დაკავშირებული ოპერაციები შეასრულოს.

შემდეგი ფენაა System Utilities and Services. აქ შედის სისტემის ადმინისტრირებისთვის განკუთვნილი ხელსაწყოები და ფონური სერვისები. მაგალითად, systemd ბევრ Linux დისტრიბუციაში სისტემის ინიციალიზაციასა და სერვისების მართვაში მონაწილეობს. ისეთი ბრძანებები, როგორიცაა ls, ps და ip, მომხმარებელს ფაილების, პროცესებისა და ქსელის შესახებ ინფორმაციის მიღებაში ეხმარება.

ყველაზე ზედა დონეზე მდებარეობს Applications and User Interface — მომხმარებლის პროგრამები და მათთან ურთიერთქმედების საშუალებები. ეს შეიძლება იყოს ვებბრაუზერი, ტექსტური რედაქტორი, გრაფიკული სამუშაო გარემო ან ტერმინალი. Linux-ის გამოყენება შესაძლებელია როგორც გრაფიკული ინტერფეისით, ისე ბრძანების სტრიქონით (CLI).

მაგალითად, როდესაც Linux-ის ტერმინალში ბრძანებას ls უშვებ, Shell ამ ბრძანებას შესაბამის პროგრამას გადასცემს. პროგრამა საჭირო სისტემურ ფუნქციებს იყენებს ფაილების შესახებ ინფორმაციის მისაღებად. Kernel ფაილურ სისტემასთან და საჭიროების შემთხვევაში საცავის მოწყობილობასთან დაკავშირებულ ოპერაციებს მართავს, ხოლო მიღებული შედეგი ტერმინალში გამოჩნდება.

Linux-ის მნიშვნელოვანი თავისებურებაა ისიც, რომ Linux Kernel და Linux Distribution ერთი და იგივე არ არის. Kernel სისტემის ცენტრალური ნაწილია, ხოლო დისტრიბუცია აერთიანებს Kernel-ს, სისტემურ პროგრამებს, ბიბლიოთეკებს, პაკეტების მენეჯერს და სხვა კომპონენტებს. მაგალითად, Ubuntu, Debian და Fedora Linux-ის დისტრიბუციებია.

ამრიგად, Linux-ის არქიტექტურა აერთიანებს აპარატურას, Kernel-ს, სისტემურ ბიბლიოთეკებს, სერვისებსა და მომხმარებლის პროგრამებს. ამ კომპონენტების ურთიერთქმედება უზრუნველყოფს სისტემის მუშაობას, რესურსების მართვასა და პროგრამების აპარატურასთან კონტროლირებულ წვდომას.
