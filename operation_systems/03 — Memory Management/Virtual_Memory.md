Virtual Memory (ვირტუალური მეხსიერება) არის მეხსიერების მართვის მექანიზმი, რომელიც თითოეულ პროცესს საკუთარ ვირტუალურ მისამართთა სივრცეს აძლევს. პროგრამა ამ მისამართებს იყენებს ისე, რომ არ სჭირდება იცოდეს, RAM-ის რომელ ფიზიკურ მისამართზე ინახება მისი მონაცემები. ვირტუალური მისამართების ფიზიკურ მეხსიერებასთან დაკავშირებას ოპერაციული სისტემა და პროცესორის Memory Management Unit (MMU) უზრუნველყოფენ.

ვირტუალური მეხსიერების მთავარი უპირატესობაა პროცესების იზოლაცია და მეხსიერების მოქნილი მართვა. თითოეული პროცესი ჩვეულებრივ საკუთარ მისამართთა სივრცეში მუშაობს, რის გამოც ერთი პროგრამა პირდაპირ ვერ კითხულობს ან ცვლის მეორე პროგრამის მეხსიერებას შესაბამისი ნებართვის გარეშე. ეს ზრდის სისტემის უსაფრთხოებასა და სტაბილურობას.

მაგალითად, როდესაც ბრაუზერსა და ტექსტურ რედაქტორს ერთდროულად ვუშვებთ, ორივე პროგრამას საკუთარი ვირტუალური მისამართთა სივრცე აქვს. მიუხედავად იმისა, რომ ორივე იყენებს ერთსა და იმავე ფიზიკურ RAM-ს, მათი მისამართები ერთმანეთისგან დამოუკიდებლად იმართება. ოპერაციული სისტემა და MMU განსაზღვრავენ, რომელ ფიზიკურ მეხსიერებას შეესაბამება კონკრეტული ვირტუალური მისამართი და აქვს თუ არა პროცესს მასზე წვდომის უფლება.

ვირტუალური მეხსიერება ასევე საშუალებას იძლევა, რომ პროგრამის ყველა მონაცემი მუდმივად RAM-ში არ იყოს. საჭიროების მიხედვით, ოპერაციულ სისტემას შეუძლია მეხსიერების ზოგიერთი გვერდი დისკზე არსებულ სპეციალურ სივრცეში გადაიტანოს და მოგვიანებით კვლავ RAM-ში დააბრუნოს. Windows-ში ამ პროცესთან დაკავშირებულია Page File, ხოლო Linux-ში შეიძლება გამოიყენებოდეს Swap Partition ან Swap File. თუმცა ვირტუალური მეხსიერება მხოლოდ დისკზე მონაცემების გადატანას არ ნიშნავს — მისი ძირითადი საფუძველი ვირტუალური მისამართების ფიზიკურ მეხსიერებასთან დაკავშირება და პროცესების იზოლაციაა.

როდესაც პროგრამა ისეთ მეხსიერების გვერდს მიმართავს, რომელიც ამ მომენტში RAM-ში შესაბამისი სახით ხელმისაწვდომი არ არის, შეიძლება წარმოიქმნას Page Fault. ეს თავისთავად შეცდომას ან პროგრამის ავარიულ დასრულებას არ ნიშნავს. ოპერაციული სისტემა ამუშავებს მოთხოვნას და, თუ წვდომა ნებადართულია, საჭირო გვერდს RAM-ში ათავსებს ან შესაბამის მეხსიერების რუკას აახლებს. თუ გვერდის აღდგენა დისკიდან გახდა საჭირო, ოპერაცია RAM-თან შედარებით გაცილებით ნელი იქნება.

ვირტუალური მეხსიერების გადაჭარბებულმა გამოყენებამ შეიძლება სისტემის წარმადობა მკვეთრად შეამციროს. თუ RAM აღარ არის საკმარისი და სისტემა ხშირად უწევს მეხსიერების გვერდების დისკზე გადატანა და უკან დაბრუნება, წარმოიქმნება მდგომარეობა, რომელსაც Thrashing ეწოდება. ასეთ დროს კომპიუტერი შეიძლება ძალიან შენელდეს, რადგან დროის დიდი ნაწილი მეხსიერების გვერდების გადაადგილებას ხმარდება და არა პროგრამების შესრულებას.

ამრიგად, Virtual Memory თანამედროვე ოპერაციული სისტემის ერთ-ერთი უმნიშვნელოვანესი მექანიზმია. ის უზრუნველყოფს პროცესების იზოლაციას, ვირტუალური მისამართების მოქნილ მართვას და მეხსიერების ეფექტიან გამოყენებას. ამ მექანიზმის უკეთ გასაგებად შემდეგ უნდა გავეცნოთ Paging-ს — მეხსიერების გვერდებად დაყოფისა და მართვის პრინციპს.
