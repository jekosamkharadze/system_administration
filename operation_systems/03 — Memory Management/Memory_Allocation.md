Memory Allocation არის პროცესი, რომლის დროსაც ოპერაციული სისტემა ან პროგრამული გარემო პროგრამას, პროცესს ან მის კონკრეტულ მონაცემებს მეხსიერებას გამოუყოფს. პროგრამას მუშაობისას სჭირდება ადგილი, სადაც შეინახავს ცვლადებს, ობიექტებს, დროებით მონაცემებსა და შესრულებისთვის აუცილებელ სხვა ინფორმაციას. Memory Allocation უზრუნველყოფს, რომ ამ მონაცემებისთვის საჭირო მეხსიერება გამოიყოს და სწორად გამოიყენებოდეს.

მაგალითად, როდესაც კომპიუტერში ბრაუზერს ვხსნით, მას მუშაობისთვის მეხსიერება სჭირდება. ოპერაციული სისტემა პროცესს ვირტუალურ მისამართთა სივრცეს უქმნის, ხოლო საჭიროებისამებრ მეხსიერების შესაბამის გვერდებს ფიზიკურ RAM-ს უკავშირებს. პროგრამის მუშაობისას მოთხოვნები შეიძლება გაიზარდოს, ამიტომ მეხსიერების გამოყოფა მხოლოდ პროგრამის გაშვების მომენტში არ ხდება — ის შეიძლება შესრულების დროსაც გაგრძელდეს.

მეხსიერების გამოყოფის ორი მნიშვნელოვანი სახეა Stack Allocation და Heap Allocation. Stack, ანუ სტეკი, ჩვეულებრივ გამოიყენება ფუნქციების გამოძახებებთან დაკავშირებული მონაცემებისთვის, მაგალითად, ლოკალური ცვლადებისა და დაბრუნების მისამართებისთვის. ფუნქციის დასრულებისას შესაბამისი სტეკის სივრცე, როგორც წესი, ავტომატურად თავისუფლდება. Heap კი გამოიყენება იმ მონაცემებისთვის, რომელთა სიცოცხლის ხანგრძლივობა ყოველთვის არ ემთხვევა ერთი ფუნქციის შესრულების პერიოდს. Heap-ზე მეხსიერების მოთხოვნა შეიძლება პროგრამის მუშაობის დროს მოხდეს, ხოლო მისი გათავისუფლება დამოკიდებულია პროგრამირების ენაზე და გამოყენებულ მეხსიერების მართვის მექანიზმებზე.

მაგალითად, ფუნქციის შიგნით შექმნილი ჩვეულებრივი ლოკალური ცვლადი ხშირად Stack-ზე ინახება, ხოლო დინამიკურად შექმნილი ობიექტი შეიძლება Heap-ზე განთავსდეს. ეს მხოლოდ ზოგადი მაგალითია: მეხსიერების რეალური განაწილება დამოკიდებულია პროგრამირების ენაზე, კომპილატორზე და შესრულების გარემოზე.

მეხსიერების გამოყოფა შეიძლება იყოს Static Allocation ან Dynamic Allocation. Static Allocation-ის დროს მეხსიერების საჭიროება და განაწილების ზოგიერთი მახასიათებელი პროგრამის შესრულებამდე განისაზღვრება. Dynamic Allocation კი გულისხმობს მეხსიერების მოთხოვნასა და გამოყოფას პროგრამის მუშაობის დროს, როცა საჭიროება წარმოიქმნება. დინამიკური გამოყოფა მოქნილია, თუმცა თუ მეხსიერება დროულად არ თავისუფლდება, შეიძლება მეხსიერების გაჟონვა (Memory Leak) წარმოიქმნას.

ოპერაციული სისტემა მეხსიერების გამოყოფის პროცესში აკონტროლებს პროცესების ვირტუალურ მისამართთა სივრცეებსა და ფიზიკურ რესურსებთან მათ კავშირს. უშუალოდ Stack-ისა და Heap-ის მართვაში კი ხშირად მონაწილეობს პროგრამირების ენის შესრულების გარემოც, მაგალითად, Runtime ან Garbage Collector. ამიტომ მნიშვნელოვანია გავარჩიოთ ოპერაციული სისტემის მიერ მეხსიერების მართვა და პროგრამის შიგნით მეხსიერების გამოყენების ლოგიკა.

ამრიგად, Memory Allocation არის მეხსიერების მართვის ძირითადი ნაწილი, რომელიც უზრუნველყოფს პროგრამებისთვის საჭირო სივრცის გამოყოფას. მისი სწორად მართვა აუცილებელია პროგრამის სტაბილური მუშაობისთვის, რესურსების ეფექტიანი გამოყენებისა და მეხსიერების გაჟონვის მსგავსი პრობლემების თავიდან ასაცილებლად.
