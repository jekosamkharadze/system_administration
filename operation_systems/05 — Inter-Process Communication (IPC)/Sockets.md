Socket არის კომუნიკაციის ბოლო წერტილი (communication endpoint), რომლის საშუალებითაც პროგრამებს მონაცემების გაცვლა შეუძლიათ. Socket-ები გამოიყენება როგორც ერთსა და იმავე კომპიუტერში გაშვებულ პროცესებს შორის, ისე ქსელით დაკავშირებულ სხვადასხვა კომპიუტერზე არსებულ პროგრამებს შორის.

მაგალითად, როდესაც ბრაუზერში ვებსაიტს ხსნი, ბრაუზერი სერვერს უკავშირდება და მასთან მონაცემებს ცვლის. ამ კომუნიკაციისთვის პროგრამები Socket-ებს იყენებენ. ბრაუზერი აგზავნის მოთხოვნას, სერვერი ამუშავებს მას და პასუხს უკან აბრუნებს. ამ პროცესის შედეგად ბრაუზერში ვებსაიტის შინაარსი ჩნდება.

ქსელურ კომუნიკაციაში Socket ხშირად დაკავშირებულია IP მისამართთან და პორტთან. IP მისამართი განსაზღვრავს ქსელში შესაბამის მოწყობილობას ან ინტერფეისს, ხოლო პორტი კონკრეტულ მოწყობილობაზე შესაბამის აპლიკაციას ან ქსელურ სერვისს ეხმარება. მაგალითად, ვებკომუნიკაციაში ხშირად გამოიყენება TCP პორტები 80 და 443. Socket-ის ქსელური მისამართი ხშირად მოიცავს IP მისამართსა და პორტს, თუმცა Socket-ის ზუსტი იდენტიფიკაცია გამოყენებულ პროტოკოლსა და მისამართების ოჯახზეც არის დამოკიდებული.

არსებობს Socket-ების რამდენიმე ტიპი. TCP Socket გამოიყენება TCP პროტოკოლით კომუნიკაციისთვის. TCP კავშირის დამყარებას უზრუნველყოფს და მონაცემების საიმედო, თანმიმდევრულ გადაცემას ცდილობს. UDP Socket კი გამოიყენება UDP პროტოკოლით მონაცემთა გადაცემისთვის, რომელიც კავშირის დამყარებას არ მოითხოვს და მონაცემების მიწოდების გარანტიას არ იძლევა. რომელი ტიპი გამოიყენება, კონკრეტული პროგრამის საჭიროებაზეა დამოკიდებული.

Socket-ები მხოლოდ ინტერნეტისთვის არ არის განკუთვნილი. ერთ კომპიუტერში გაშვებულ პროგრამებსაც შეუძლიათ ერთმანეთთან Socket-ებით კომუნიკაცია. მაგალითად, Linux-ში არსებობს Unix Domain Socket, რომელიც ადგილობრივ სისტემაში პროცესებს შორის მონაცემების გაცვლის საშუალებას იძლევა და ამისთვის ქსელის IP მისამართი აუცილებელი არ არის.

ოპერაციული სისტემა Socket-ებთან დაკავშირებულ რესურსებსა და ოპერაციებს მართავს. პროგრამას შეუძლია Socket-ის შექმნა, მასთან დაკავშირება, მონაცემების გაგზავნა და მიღება, ხოლო კომუნიკაციის დასრულების შემდეგ Socket-ის დახურვა. სერვერის პროგრამა ხშირად კონკრეტულ მისამართსა და პორტზე ელოდება შემომავალ კავშირებს, კლიენტის პროგრამა კი მას უკავშირდება.

მნიშვნელოვანია, ერთმანეთისგან განვასხვაოთ Socket და Port. Port არის ქსელური კომუნიკაციის ლოგიკური იდენტიფიკატორი, ხოლო Socket არის პროგრამული საკომუნიკაციო ბოლო წერტილი, რომელიც პორტს, მისამართსა და პროტოკოლს შეიძლება უკავშირდებოდეს. ასევე, Socket არ არის თავად TCP ან UDP — ის პროგრამებს ამ პროტოკოლების გამოყენების საშუალებას აძლევს.

ამრიგად, Socket-ები ოპერაციულ სისტემაში კომუნიკაციის ერთ-ერთი ძირითადი მექანიზმია. მათი საშუალებით პროგრამებს შეუძლიათ მონაცემების გაცვლა როგორც ერთი კომპიუტერის ფარგლებში, ისე ქსელის გავლით, რაც აუცილებელია ვებბრაუზერების, სერვერების, ჩატაპლიკაციებისა და მრავალი სხვა ქსელური პროგრამის მუშაობისთვის.
