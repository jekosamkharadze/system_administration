Bootloader არის პროგრამა ან პროგრამული კომპონენტი, რომელიც კომპიუტერის ჩართვისას უზრუნველყოფს ოპერაციული სისტემის Kernel-ის ჩატვირთვას და მისთვის მართვის გადაცემას.

კომპიუტერის ჩართვისას ოპერაციული სისტემა მყისიერად არ იწყებს მუშაობას. ჯერ Firmware (BIOS ან UEFI) ამზადებს სისტემას და განსაზღვრავს, საიდან უნდა დაიწყოს ჩატვირთვა. შემდეგ პროცესში მონაწილეობს Bootloader, რომელიც პოულობს ოპერაციული სისტემის საჭირო კომპონენტებს, მეხსიერებაში ტვირთავს Kernel-ს და მას მართვას გადასცემს.

მარტივად რომ ვთქვათ, Bootloader არის შუამავალი Firmware-სა და ოპერაციული სისტემის Kernel-ს შორის.

როგორ მუშაობს Bootloader?

კომპიუტერის ჩატვირთვის პროცესი შეგვიძლია ასე წარმოვადგინოთ:

Firmware → Bootloader → Kernel → System Initialization → Login

პირველ ეტაპზე Firmware ამოწმებს და საწყის მდგომარეობაში მოჰყავს საჭირო აპარატურული კომპონენტები. შემდეგ ის განსაზღვრული ჩატვირთვის ჩანაწერის მიხედვით იწყებს Bootloader-ის გაშვებას.

Bootloader პოულობს ოპერაციული სისტემის Kernel-ს და საჭიროების შემთხვევაში სხვა კომპონენტებსაც, მაგალითად Linux-ის initramfs-ს. ამის შემდეგ Kernel-ს გადასცემს მართვას. Kernel აგრძელებს ოპერაციული სისტემის ინიციალიზაციას, ხოლო მოგვიანებით იტვირთება სისტემური სერვისები და ჩნდება შესვლის ეკრანი.

BIOS და UEFI — როგორ იწყება Bootloader-ის ჩატვირთვა?

Bootloader-ის ჩატვირთვის გზა დამოკიდებულია იმაზე, კომპიუტერი Legacy BIOS რეჟიმს იყენებს თუ UEFI-ს.

BIOS-ის შემთხვევაში Firmware ჩატვირთვის მოწყობილობაზე ეძებს ჩატვირთვის კოდს. ტრადიციულ MBR სქემაში საწყისი კოდი დისკის პირველ სექტორშია განთავსებული და შემდგომი ჩატვირთვის ეტაპის დაწყებას უზრუნველყოფს.

UEFI-ის შემთხვევაში Firmware-ს შეუძლია შესაბამისი EFI პროგრამის გაშვება სპეციალური დანაყოფიდან, რომელსაც EFI System Partition (ESP) ეწოდება. ამ დანაყოფზე შეიძლება განთავსებული იყოს, მაგალითად, Windows Boot Manager ან Linux-ის Bootloader-ის ფაილი.

მნიშვნელოვანია, რომ BIOS და UEFI ერთი და იგივე არ არის, ხოლო Bootloader მათი შემცვლელი არ არის — ის ჩატვირთვის პროცესის ცალკე კომპონენტია.

Windows-ისა და Linux-ის Bootloader-ები:

Windows-სა და Linux-ს ჩატვირთვისთვის განსხვავებული პროგრამული კომპონენტები შეიძლება ჰქონდეთ.

Windows-ში გამოიყენება Windows Boot Manager, რომელიც ჩატვირთვის პროცესს მართავს და განსაზღვრავს, რომელი ოპერაციული სისტემა უნდა ჩაიტვირთოს. შემდეგ Windows Boot Loader იტვირთება და Windows-ის Kernel-ის მეხსიერებაში ჩატვირთვას უზრუნველყოფს.

Linux-ში ხშირად გამოიყენება GRUB (GRand Unified Bootloader). GRUB-ს შეუძლია აჩვენოს მენიუ, საიდანაც მომხმარებელი ირჩევს ოპერაციულ სისტემას ან Kernel-ის კონკრეტულ ვერსიას. ზოგიერთ სისტემაში გამოიყენება სხვა გადაწყვეტილებებიც, მაგალითად systemd-boot.

რა ფუნქციები აქვს Bootloader-ს?

Bootloader-ის ძირითადი დანიშნულება Kernel-ის ჩატვირთვაა, თუმცა მას სხვა ფუნქციებიც შეიძლება ჰქონდეს. მაგალითად, შეუძლია მომხმარებელს შესთავაზოს რამდენიმე ოპერაციული სისტემიდან ერთ-ერთის არჩევა, Linux-ის აღდგენის რეჟიმის გაშვება ან Kernel-ისთვის დამატებითი პარამეტრების გადაცემა.

ზოგიერთ კონფიგურაციაში Bootloader ასევე გამოიყენება სხვა ჩამტვირთველი კომპონენტის გასაშვებად. ამ პროცესს Chainloading ეწოდება.

Secure Boot და უსაფრთხო ჩატვირთვა:

UEFI-ის მქონე ბევრ სისტემაში შესაძლებელია Secure Boot-ის გამოყენება. მისი მიზანია ჩატვირთვის პროცესში შესაბამისი ციფრული ხელმოწერების შემოწმება, რათა სისტემამ მხოლოდ ნდობით აღჭურვილი და დაშვებული ჩამტვირთველი კომპონენტები გაუშვას.

Secure Boot თავად Bootloader არ არის. ის უსაფრთხოების მექანიზმია, რომელიც ჩატვირთვის გარკვეული ეტაპების სანდოობის შემოწმებას ეხმარება.

რა ხდება, თუ Bootloader დაზიანებულია?

თუ Bootloader აკლია ან დაზიანებულია, კომპიუტერმა შეიძლება ვერ შეძლოს ოპერაციული სისტემის ჩატვირთვა. ასეთ დროს შეიძლება გამოჩნდეს შეტყობინებები, როგორიცაა No bootable device, Windows Boot Manager-ის შეცდომა ან Linux-ის GRUB rescue გარემო.

თუმცა მსგავსი შეცდომები ყოველთვის Bootloader-ის დაზიანებას არ ნიშნავს. მიზეზი შეიძლება იყოს არასწორი Boot Order, დისკის პრობლემა ან დაკარგული ჩატვირთვის ჩანაწერი. ამიტომ პრობლემის მოგვარებამდე საჭიროა მიზეზის დადგენა.

შეჯამება:

Bootloader არის ჩატვირთვის პროცესის მნიშვნელოვანი კომპონენტი, რომელიც Firmware-ის შემდეგ იწყებს მუშაობას და ოპერაციული სისტემის Kernel-ის ჩატვირთვას უზრუნველყოფს. Windows-ში გამოიყენება Windows Boot Manager და Windows Boot Loader, ხოლო Linux-ში ხშირად გვხვდება GRUB.

განსხვავება:

Firmware (BIOS/UEFI) — ამზადებს აპარატურას და იწყებს ჩატვირთვის პროცესს.

Bootloader — პოულობს და მეხსიერებაში ტვირთავს Kernel-ს.

Kernel — იწყებს ოპერაციული სისტემის ძირითადი ფუნქციების შესრულებას.
