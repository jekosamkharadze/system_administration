CPU (Central Processing Unit) — კომპიუტერის მთავარი გამომთვლელი კომპონენტია, რომელიც ასრულებს პროგრამების ინსტრუქციებს და ამუშავებს მონაცემებს.

ძირითადი ფუნქციები
ასრულებს პროგრამების ინსტრუქციებს.
ამუშავებს მონაცემებს.
აკონტროლებს კომპიუტერის სხვადასხვა ოპერაციას.
ურთიერთქმედებს RAM-თან, Storage-თან და სხვა კომპონენტებთან.
ძირითადი მახასიათებლები
Cores (ბირთვები) — დამოუკიდებელი დამუშავების ერთეულები. მეტი ბირთვი საშუალებას იძლევა მეტი სამუშაო შესრულდეს პარალელურად.
Threads (ნაკადები) — პროცესორის მიერ ერთდროულად დასამუშავებელი ლოგიკური სამუშაო ერთეულები.
Clock Speed — პროცესორის მუშაობის სიხშირე, რომელიც იზომება GHz-ში.
Cache — ძალიან სწრაფი მეხსიერება პროცესორში, რომელიც ხშირად გამოყენებულ მონაცემებს დროებით ინახავს.

CPU და Motherboard

პროცესორი პირდაპირ უნდა იყოს თავსებადი დედაპლატასთან. განსაკუთრებით მნიშვნელოვანია:

Socket — პროცესორის დასამაგრებელი სოკეტი.
Motherboard-ის მხარდაჭერა კონკრეტული CPU-სთვის.
BIOS/UEFI-ის შესაბამისი ვერსია.
მარტივი მაგალითი

თუ დედაპლატა იყენებს AM5 socket-ს, მასზე მხოლოდ AM5-თან თავსებადი პროცესორები შეიძლება დამონტაჟდეს.

მთავარი დასამახსოვრებელი:
