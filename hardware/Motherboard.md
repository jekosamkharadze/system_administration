Motherboard (დედაპლატა) არის კომპიუტერის მთავარი ბეჭდური მიკროსქემული დაფა, რომელზეც თავსდება ან ერთდება კომპიუტერის ძირითადი კომპონენტები.
მისი მთავარი ფუნქციაა კომპონენტებს შორის კავშირის, მონაცემთა გაცვლისა და კვების ორგანიზება.

Motherboard-ზე ან მასთან დაკავშირებულია:
    CPU
    RAM
    GPU
    SSD/HDD
    PSU
    USB მოწყობილობები
    Fan-ები
    Audio მოწყობილობები
    Network მოწყობილობები

Motherboard ძირითადად უზრუნველყოფს:
    კომპონენტების ფიზიკურ შეერთებას;
    მონაცემების გადაცემას კომპონენტებს შორის;
    ელექტროენერგიის მიწოდების ორგანიზებას;
    CPU-სა და RAM-ის კომუნიკაციას;
    PCIe მოწყობილობების დაკავშირებას;
    Storage მოწყობილობების დაკავშირებას;
    USB და სხვა I/O მოწყობილობების მხარდაჭერას;
    Firmware-ის, BIOS/UEFI-ის მუშაობას.


CPU Socket არის Motherboard-ზე არსებული სოკეტი, რომელშიც CPU თავსდება.
Socket განსაზღვრავს, რომელი პროცესორების გამოყენებაა შესაძლებელი.
თუ CPU-სა და Motherboard-ის Socket არ შეესაბამება, ისინი ერთმანეთთან თავსებადი არ არიან.
თუმცა მხოლოდ Socket-ის დამთხვევა ყოველთვის საკმარისი არ არის — საჭიროა CPU Support List-ისა და BIOS/UEFI მხარდაჭერის შემოწმებაც.

დედაპლატაზე არსებობს chipset რომელიც უზრუნველყოფს სხვადასხვა hardware ფუნქციის მხარდაჭერასა და კონფიგურაციას.

Motherboard-ზე განთავსებულია RAM-ის სლოტები.
Desktop სისტემებში ძირითადად გამოიყენება:

    DIMM Slots
    მაგალითად Motherboard-ს შეიძლება ჰქონდეს:
    2 RAM Slot;
    4 RAM Slot;
    8 RAM Slot.

RAM-ის ტიპი Motherboard-ის მიხედვით განისაზღვრება, მაგალითად:
DDR4 ან DDR5
DDR4 RAM-ს DDR5 Slot-ში ვერ ჩავსვამთ.


დედაპლატაზე გვხვდება PCLe Slots(Peripheral Component Interconnect Express), ყველაზე გავრცელებული სლოტია  PCIe x16, რომელიც უმეტეს შემთხვევაში GPU-სთვის გამოიყენება


Motherboard-ზე შეიძლება იყოს ერთი ან რამდენიმე M.2 Slot.
M.2 Slot ხშირად გამოიყენება SSD-ის დასაყენებლად.
მაგრამ ყველა M.2 Slot ერთნაირი არ არის.
ზოგი შეიძლება მხარს უჭერდეს:
    NVMe-ს;
    SATA-ს;
    ორივეს.
ამიტომ ყოველთვის უნდა შევამოწმოთ კონკრეტული Motherboard-ის სპეციფიკაცია.

არსებობს რამოდენიმე ზომის დედაპლატა(form factor)
ყველაზე გავრცელებული ზომებია: 
    E-ATX - რომელიც დიდი ზომის კომპიუტერებში გამოიყენება;
    ATX - სტანდარტულ Desktop კომპიუტერებში გამოიყენება;
    Micro-ATX - უფრო პატარა, მაგრამ საკმაოდ სრულფასოვანი;
    Mini-ITX  -პატარა კომპაქტური სისტემები.

დასკვა:
    Motherboard არის კომპიუტერის მთავარი პლატფორმა, რომელიც CPU-ს, RAM-ს, GPU-ს, Storage-ს და სხვა მოწყობილობებს ერთმანეთთან აკავშირებს და მათ შორის მონაცემთა გაცვლასა და კვების ორგანიზებას უზრუნველყოფს.

    მისი მთავარი ნაწილებია:

        CPU Socket → CPU
        RAM Slots → RAM
        PCIe Slots → GPU/Expansion Cards
        M.2/SATA → Storage
        VRM → CPU-ის კვების რეგულირება
        BIOS/UEFI → Hardware-ის ინიციალიზაცია და სისტემის ძირითადი პარამეტრები
        ATX/mATX/Mini-ITX → Motherboard-ის ზომა და ფორმ-ფაქტორი
