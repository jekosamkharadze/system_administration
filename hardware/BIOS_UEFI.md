BIOS (Basic Input/Output System) და UEFI (Unified Extensible Firmware Interface) არის Motherboard-ზე არსებული Firmware, რომელიც კომპიუტერის ჩართვისას Hardware-ის ინიციალიზაციას ახდენს და Operating System-ის ჩატვირთვის პროცესს იწყებს. თანამედროვე კომპიუტერებში ძირითადად UEFI გამოიყენება, ხოლო BIOS უფრო ძველი ტექნოლოგიაა. ყოველდღიურ საუბარში UEFI-საც ხშირად  „BIOS-ს“ უწოდებენ.

კომპიუტერის ჩართვისას პირველ რიგში მუშაობას იწყებს Motherboard-ის Firmware. ის ამოწმებს და ამზადებს ძირითად Hardware-ს, მაგალითად CPU-ს, RAM-ს, Storage-სა და სხვა აუცილებელ მოწყობილობებს. ამ პროცესს უკავშირდება POST (Power-On Self-Test). თუ მნიშვნელოვანი Hardware-ის პრობლემა აღმოჩნდა, სისტემამ შეიძლება საერთოდ ვერ დაიწყოს ჩატვირთვა და მომხმარებელს შეცდომა აჩვენოს ან Beep Code-ები გამოიყენოს, თუ Motherboard-ს ეს ფუნქცია აქვს.

POST-ის შემდეგ Firmware ეძებს იმ მოწყობილობას, საიდანაც Operating System უნდა ჩაიტვირთოს. ამას განსაზღვრავს Boot Order. მაგალითად, Boot Order-ში შეიძლება პირველი იყოს USB, შემდეგ SSD. თუ USB-ზე Bootable Operating System არსებობს, სისტემა შეიძლება იქიდან ჩაიტვირთოს; წინააღმდეგ შემთხვევაში შემდეგ მოწყობილობას შეამოწმებს.

UEFI-ს საშუალებით შესაძლებელია კომპიუტერის Hardware-ისა და Boot პროცესის სხვადასხვა პარამეტრის კონფიგურაცია. მაგალითად, შეგვიძლია შევცვალოთ Boot Order, ვნახოთ CPU-სა და RAM-ის ინფორმაცია, ჩავრთოთ ან გამოვრთოთ გარკვეული Hardware ფუნქციები, დავაკონფიგურიროთ Fan-ების მუშაობა და RAM-ის შესაბამისი პროფილები, თუ სისტემა მათ მხარდაჭერას უზრუნველყოფს.

BIOS/UEFI-ში შესასვლელად კომპიუტერის ჩართვისას ხშირად გამოიყენება Delete, F2, ზოგ სისტემაში კი F10, F12 ან სხვა ღილაკი. კონკრეტული ღილაკი დამოკიდებულია Motherboard-ის ან Laptop-ის მწარმოებელზე.

ძველი BIOS ძირითადად იყენებს Legacy Boot რეჟიმს და აქვს გარკვეული ტექნიკური შეზღუდვები. UEFI უფრო თანამედროვე Firmware Interface-ია, აქვს უკეთესი Boot მექანიზმი და თანამედროვე სისტემების ფუნქციების მხარდაჭერა. UEFI ხშირად მუშაობს GPT Partition Table-თან და შეუძლია დიდი ზომის Storage მოწყობილობებიდან ჩატვირთვის მხარდაჭერა.            
    ("Firmware არის სპეციალური პროგრამული უზრუნველყოფა, რომელიც უშუალოდ Hardware-ში ან Hardware-ის მეხსიერებაშია ჩაწერილი და მოწყობილობის მუშაობას  მართავს.")

UEFI-ს ერთ-ერთი მნიშვნელოვანი ფუნქციაა Secure Boot. Secure Boot ამოწმებს Boot პროცესში გამოყენებული პროგრამული კომპონენტების ციფრულ ხელმოწერებს და ეხმარება არასანდო Bootloader-ის გაშვების თავიდან აცილებას. ეს უსაფრთხოების მექანიზმია და არა Antivirus.

BIOS/UEFI-ში შესაძლებელია სხვადასხვა Hardware პარამეტრის შეცვლა. მაგალითად, შესაძლებელია Boot Device-ის არჩევა, Virtualization-ის ჩართვა, Fan-ის პარამეტრების შეცვლა და RAM-ის შესაბამისი პროფილის ჩართვა. თუმცა უცნობი პარამეტრების შემთხვევით შეცვლა არ არის რეკომენდებული, რადგან არასწორმა კონფიგურაციამ შეიძლება სისტემა არასტაბილური გახადოს ან საერთოდ ვერ ჩაიტვირთოს.

ზოგიერთ შემთხვევაში საჭიროა BIOS/UEFI-ის განახლება. ამას BIOS/UEFI Update ან Firmware Update ეწოდება. განახლებამ შეიძლება დაამატოს ახალი CPU-ის მხარდაჭერა, გამოასწოროს შეცდომები ან გააუმჯობესოს თავსებადობა და სტაბილურობა. განახლებისას მნიშვნელოვანია ზუსტად შესაბამისი Motherboard-ის Firmware-ის გამოყენება, რადგან არასწორი Firmware-ის ჩაწერამ შეიძლება Motherboard-ის მუშაობა შეაფერხოს.

თუ BIOS/UEFI-ის პარამეტრები არასწორად შეიცვალა, შესაძლებელია მათი საწყის მდგომარეობაში დაბრუნება. ამას ხშირად Clear CMOS ან Load Optimized Defaults მეთოდით აკეთებენ. Clear CMOS-ისთვის Motherboard-ზე შეიძლება არსებობდეს შესაბამისი Jumper ან Button, ხოლო ზოგ შემთხვევაში CMOS Battery-ის ამოღებაც გამოიყენება, თუმცა კონკრეტული მეთოდი Motherboard-ის ინსტრუქციის მიხედვით უნდა შესრულდეს.



დასკვნა: BIOS/UEFI არის Motherboard-ის Firmware, რომელიც კომპიუტერის ჩართვისას Hardware-ს ამზადებს სამუშაოდ, ასრულებს POST-ს, ადგენს Boot პროცესს და შემდეგ გადასცემს კონტროლს Operating System-ის Bootloader-ს. თანამედროვე კომპიუტერებში ძირითადად UEFI გამოიყენება, ხოლო BIOS ხშირად ამ პროცესის ზოგად სახელადაც გამოიყენება.
