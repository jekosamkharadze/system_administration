RAM (Random Access Memory) არის კომპიუტერის ოპერატიული მეხსიერება, სადაც დროებით ინახება მონაცემები და პროგრამების ის ნაწილი, რომელსაც CPU ამჟამად იყენებს. RAM არის Volatile Memory, რაც ნიშნავს, რომ კომპიუტერის გამორთვისას მასში შენახული მონაცემები იკარგება.  SSD/HDD-ზე მონაცემები მუდმივად ინახება, ხოლო RAM-ში ისინი დროებით იტვირთება, რათა CPU-მ მათზე სწრაფად იმუშაოს.


როდესაც პროგრამას ვხსნით, მისი საჭირო მონაცემები storage-დან RAM-ში იტვირთება. CPU-ს შეუძლია RAM-იდან საჭირო მონაცემების მიღება და დამუშავება.  RAM-ის მთავარი უპირატესობა არის ის, რომ მასზე მონაცემებზე წვდომა SSD/HDD-ზე ბევრად სწრაფია.

RAM-ის მოცულობა იზომება GB-ში, ძირითადად RAM გვხვდება 4, 8, 16, 32, 64 GB ზომის.
მეტი RAM საშუალებას აძლევს სისტემას ერთდროულად მეტი პროგრამისა და მონაცემის მეხსიერებაში შენარჩუნება შეძლოს.
მაგრამ მეტი RAM ავტომატურად არ ნიშნავს უფრო სწრაფ კომპიუტერს. თუ პროგრამას 8 GB სჭირდება, 32 GB-ის არსებობა თავისთავად მის შესრულებას ოთხჯერ არ დააჩქარებს.

RAM-ის სიჩქარე დაკავშირებულია მონაცემთა გადაცემის სიჩქარესთან.
თანამედროვე RAM-ის სპეციფიკაციებში ხშირად გამოიყენება MT/s (Mega Transfers per second).
მაგალითად: DDR5-6000 → 6000 MT/s

Latency არის დროის დაყოვნება მეხსიერებიდან მონაცემის მოთხოვნასა და მის მიღებას შორის.
RAM-ის სპეციფიკაციებში ხშირად გვხვდება:
CL — CAS Latency
მაგალითად: DDR5-6000 CL30
CL-ის მნიშვნელობის შეფასება ყოველთვის RAM-ის სიჩქარესთან ერთად უნდა მოხდეს.

DDR ნიშნავს -Double Data Rate 
DDR მეხსიერება მონაცემთა გადაცემას Clock Cycle-ის ორივე მხარეს ახორციელებს.
ძირითადი თაობებია - DDR; DDR2;DDR3; DDR4; DDR5
რაც ახალი თაობისაა RAM უფრო მეტი სიჩქარისაა ის.

არსებობს Single Channel და Dual Channel.
Single Channel დროს Memory Controller იყენებს მხოლოდ ერთ სლოტს  RAM-თან კომუნიკაციისთვის.
ხოლო Dual Channel დროს გამოიყენება ორი სლოტი და ორი RAM,  2*4GB RAM-ის გამოყენება უკეთესია ვიდრე მხოლოდ ერთი 8GB RAM-ის.

როდესაც კომპიუტერის დატვირთვისას  RAM მეხსიერების ლიმიტი იწურება, ოპერაციულ სისტემას შეუძლია მეხსიერებიდან შექმნას ვირტუალური მეხსიერება და დროებით გააფართოვოს RAM-ის მეხსიერება, მაგრამ ის ვერ იქნება ისეთივე სწრაფი როგორიც რეალური RAM.

RAM-ის ყიდვისას და მისი დაყენებისას უნდა გავითვალისწინოთ რამდენიმე რამ:
DDR თაობა; დედაპლატის მხარდაჭერა; CPU-ის Memory Support; მაქსიმალური RAM Capacity; RAM-ის სიჩქარე; Memory Channel Configuration;


დასკვნა:
    RAM არის სწრაფი, დროებითი მეხსიერება, რომელსაც CPU აქტიურად იყენებს პროგრამებისა და მონაცემების დასამუშავებლად.

    Latency — წვდომის დაყოვნება;
    DDR Generation — DDR4, DDR5 და ა.შ.;
