CPU (Central Processing Unit) — კომპიუტერის მთავარი გამომთვლელი კომპონენტია, რომელიც ასრულებს პროგრამების ინსტრუქციებს და ამუშავებს მონაცემებს, მარტივად რომ ვთქვათ პროცესორი არის კომპიუტერის ტვინი.


 CPU-ს ძირითადი ფუნქციები:
  პროგრამის ინსტრუქციების შესრულება;
  არითმეტიკული გამოთვლების შესრულება;
  ლოგიკური ოპერაციების შესრულება;
  მონაცემთა დამუშავება;
  სხვა hardware კომპონენტებთან კომუნიკაცია;
  პროგრამების შესრულების პროცესის მართვა;

როგორ მუშაობს CPU:
Fetch → Decode → Execute → Write Back

fetch:
    cpu იღებს შემდეგი ინსტრუქციის მისამართს და ინსტრუქციას მეხსიერებიდან.
decode:
    cpu აანალიზებს მიღებულ ინსტრუქციას და ადგენს თუ რა ოპერაცია უნდა შესრულდეს.
execute:
    cpu ასრულებს მიღებულ ოპერაციას.
white back:
    საჭიროების შემთხვევაში მიღებული ინფორმაცი ინახება შესაბამის register-ში ან მეხსიერებაში.


პროცესორის ძირითადი კომპონენტებია:
    ALU;
    CONTROL UNIT;
    REGISTER;
    CACHE(L1,L2,L3);
    CPU CORES;
    CLOCK;
    MEMORY CONTROLLER;
    INSTRUCTION DECODER.

        ALU(arithmetic logic unit) არის პროცესორის ნაწილი რომელიც ასრულებს არითმეტიკულ ოპერაციებს, მაგალითად მიმატება, გამოკლება, შედარება, and, or,xor,not და სხვა ლოგიკურ ოპერაციებს.

        control unit პასუხისმგებელია პროცესორის მუშაობის მართვაზე, მისი ძირითადი მოვალეობაა თუ რომელი ინსტრუქცია უნდა შესრულდეს, რომელი კომპონენტი გამოიყენოს პროცესორმა, რა თანმიმდევრობით შესრულდეს ოპერაციები, სად უნდა გაიგზავნოს მონაცემები.

        რეგისტრი არის პროცესორში არსებული ძალიან პატარა და სწრაფი მეხსიერების ტიპი, რეგისტრებს პროცესორი იყენებს მიმდინარე ოპერაციების მონაცემების, მისამართების და შუალედური შედეგების შესანახად. 

        cache- ქეში არის ძალიან სწრაფი მეხსიერება რომელის პროცესორთან ახლოს ან თავად პროცესორშია ინტეგირებული, მისი მიზანია ხშირად გამოყენებული მონაცემების და ინსტრუქციების სწრაფად მიწოდება პროცესორისთვის, არსებობს L1, L2 და L3 ქეში. 
        L1 არის ყველაზე სწრაფი და მცირე მეხსიერების,
        L2 არის საშუალო სისწრაფის და საშუალო მეხსიერების,
        L3 არის ყველაზე ნელი და ყველაზე მეტი მეხსიერების მქონე.
            CPU ძალიან სწრაფად მუშაობს ხოლო RAM-ს უფრო მაღალი დაყოვება აქვს ვიდრე ქეშს, თუ პროცესორი ყოველ ჯერზე RAM-ს დაელოდება მისი მუშაობა შემცირდება.

        CPU CORE(პროცესორის ბირთვები) არის პროცესორის დამოუკიდებელი გამოთვლითი ერთეული, რომელსაც შეუძლია პროცესორის ინსტრუქციების შესრულება.  ძირითადად არსებობს 2; 4; 8; 16 CORE.  
            მაგალითად 4 ბირთვი შეიძლება მუშაობდეს მსგავსად - 1 ბირთვი -- ბრაუზერი; 2 ბირთვი -- სისტემური პროცესი; 3 ბირთვი --ვიდეოს დამუშავება; 4 ბირთვი - სხვა პროგრამა.
        შეიძლება გვქონდეს 4 ბირთვი მაგრამ იყოს 2 thread(ნაკადი), რაც გულისხმობს იმას რომ ერთ ბირთვს შეუძლია 2 სხვადასხვა ტიპის ინსტრუქცია დაამუშაოს ერთდროულად, თუ გვაქვს 4 ბირთვი და 8 thread მაშინ ერთ დროულად 4 ინსტრუქცია კი არ შესრულდება, არამედ 8.

        clock speed - CPU-სთან მუშაობის სიჩქარესთან დაკავშირებული ერთ-ერთი მნიშვნელოვანი პარამეტია CLOCK FREQUENCY - ის იზომება Hz -ჰერცებში(ასევე ხშირად გამოიყენებენ MHz,  GHz), მაგალითად 4GHz = 4 მილიარდი clock  cycle წამში

        CPU architecture - გასნაზღვრავს, როგორ არის პროცესორი ირგანიზებული და როგორ ასრულებს ინსტრუქციებს. ყველაზე ცნობილია x86-64 და ARM64.

მთავარი დასამახსოვრებელი:

   
    CPU არის კომპიუტერის ცენტრალური დამამუშავებელი კომპონენტი, რომელიც ასრულებს პროგრამის ინსტრუქციებს და ამუშავებს მონაცემებს.

    CPU-ის მნიშვნელოვანი ნაწილებია:

    ALU — არითმეტიკული და ლოგიკური ოპერაციები
    Control Unit — ინსტრუქციების შესრულების მართვა
    Registers — ძალიან სწრაფი შიდა მეხსიერება
    Cache — სწრაფი მეხსიერება CPU-სთან ახლოს
    Cores — ფიზიკური გამოთვლითი ბირთვები
    Threads — შესრულების ნაკადები
    Memory Controller — RAM-თან კომუნიკაცია
    Integrated GPU — ზოგ CPU-ში ჩაშენებული გრაფიკული პროცესორი
